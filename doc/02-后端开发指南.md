# 后端开发指南

## 分层架构

```
Seven.WebApi          → Controllers、Middleware、Program.cs
Seven.Application     → 应用服务、DTO、接口定义
Seven.Infrastructure  → EF DbContext、缓存、JWT、MinIO、Quartz
Seven.Domain          → 实体、枚举、仓储接口
Seven.Builder         → 代码生成器
Seven.Board           → 大屏/设备
```

依赖方向：`WebApi → Application → Domain ← Infrastructure`

## 新增业务模块流程

### 1. 定义实体（Seven.Domain）

```csharp
/// <summary>
/// 示例实体
/// </summary>
public class Demo : BaseEntity
{
    public int DemoId { get; set; }
    public string Name { get; set; } = string.Empty;
}
```

### 2. 添加 EF 配置（Seven.Infrastructure/Persistence/Configurations）

```csharp
public class DemoConfiguration : IEntityTypeConfiguration<Demo>
{
    public void Configure(EntityTypeBuilder<Demo> builder)
    {
        builder.ToTable("Demo");
        builder.HasKey(x => x.DemoId);
        builder.Property(x => x.Name).HasMaxLength(100).IsRequired();
    }
}
```

### 3. 注册 DbSet（SevenDbContext）

在 `SevenDbContext` 中添加 `public DbSet<Demo> Demos => Set<Demo>();`

### 4. 创建 Migration

```bash
dotnet ef migrations add AddDemo --project Seven.Infrastructure --startup-project Seven.WebApi
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

### 5. 应用服务（Seven.Application）

实现 `IDemoService`，注入 `SevenDbContext` 或 `IRepository<Demo>`。

### 6. Controller（Seven.WebApi）

```csharp
[Route("api/[controller]")]
[ApiController]
[Authorize]
public class DemoController : ControllerBase
{
    // GET/POST/PUT/DELETE 标准 CRUD
}
```

## 统一响应格式

所有 API 返回 `WebResponseContent`：

```json
{
  "status": true,
  "message": "操作成功",
  "data": {},
  "code": null
}
```

## 缓存使用

注入 `ICacheService`，写操作后调用：

```csharp
await _cache.RemoveWithDelayedDoubleDeleteAsync(cacheKey);
```

## 密码处理

禁止明文或对称加密存储密码，统一使用 `IPasswordHasher`（BCrypt 实现）。

## 注释规范

- 所有 public 成员添加 `/// <summary>` XML 文档
- Controller Action 注明权限要求
- 复杂业务逻辑添加行内注释

## 中间件顺序

Exception → TraceId → RequestLog → Authentication → Authorization → RateLimit → CORS
