# 后端开发指南

## 分层与依赖

```
Seven.WebApi          → Controllers、Hubs、Program、Swagger、健康检查
Seven.Application     → 服务接口、DTO、消息契约（无基础设施依赖）
Seven.Domain          → 实体、枚举、BaseEntity、WebResponseContent
Seven.Infrastructure  → EF、缓存、JWT、安全、MQ、Quartz、存储、邮件、中间件
Seven.Business        → 业务域服务（如工作流引擎）
Seven.Builder         → 代码生成器实现
Seven.Tests           → 单元 / 集成测试
```

依赖方向：`WebApi → Application → Domain ← Infrastructure / Business / Builder`

## 解决方案项目职责

| 项目 | 职责 |
|------|------|
| **Seven.Domain** | 纯领域模型：`Entities/*`、`Enums`、`Common`（`BaseEntity`、`ISoftDelete`、统一响应） |
| **Seven.Application** | 应用层契约：`I*Service`、请求/响应模型、MQ 事件定义；不引用 EF |
| **Seven.Infrastructure** | 技术实现与横切：DbContext、种子、缓存、认证授权、限流/防重、文件、邮件、MassTransit、Quartz、Options |
| **Seven.Business** | 可独立演进的业务服务（当前含 `WorkFlowService`），由 `AddSevenBusiness()` 注册 |
| **Seven.Builder** | 读表结构、生成 Entity/Service/Controller/Vue 模板代码 |
| **Seven.WebApi** | HTTP 入口：`Program.cs`、Controllers、SignalR Hubs、生成模板 `Template/`、`Generated/` |
| **Seven.Tests** | FluentAssertions + WebApplicationFactory 等 |

## Infrastructure 文件夹

| 目录 | 说明 |
|------|------|
| `Configuration/` | Options（Database/Cache/Jwt/Features/…） |
| `Persistence/` | `SevenDbContext`、Configurations、Migrations、DbSeeder、审计拦截器 |
| `Services/` | 系统模块服务（用户/角色/菜单/字典/日志/告警/设备…）、CrudHelper |
| `Security/` | JWT、验证码、`[Permission]`、`[RequiresFeature]`、DataScope |
| `Middleware/` | 异常、TraceId、请求日志、IP 白名单、防重 |
| `Caching/` | Memory/Redis + 延迟双删 |
| `Storage/` | 本地 / MinIO 文件存储 |
| `Messaging/` | MassTransit、Consumer、Outbox |
| `Quartz/` | 调度宿主与任务服务 |
| `Mail/` | MailKit 发信 |

## WebApi 文件夹

| 目录/文件 | 说明 |
|-----------|------|
| `Controllers/` | 手写系统 API；`Generated/` 为代码生成产物 |
| `Hubs/` | MessageHub / AlarmHub 与推送服务 |
| `Template/` | Builder 生成用的 HTML/CS 模板 |
| `Program.cs` | 管道、Swagger 分组、Features 门控 MapHub |
| `appsettings*.json` | 环境配置；**Features** 见 [14-功能开关](./14-功能开关.md) |

## 功能开关

复杂能力默认关闭或可关，见 **[14-功能开关](./14-功能开关.md)**。  
Controller 使用 `[RequiresFeature("WorkFlow")]` 等；关闭后返回 404。

## 新增业务模块流程

### 1. 定义实体（Seven.Domain）

```csharp
public class Demo : BaseEntity
{
    public int DemoId { get; set; }
    public string Name { get; set; } = string.Empty;
}
```

### 2. EF 配置 + DbSet + Migration

配置放在 `Persistence/Configurations`；在 `SevenDbContext` 增加 DbSet；执行：

```bash
cd Seven.Master/Seven.Net8
dotnet ef migrations add AddDemo --project Seven.Infrastructure --startup-project Seven.WebApi
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

### 3. 应用服务与 Controller

- 接口：`Seven.Application`
- 实现：`Seven.Infrastructure.Services` 或 `Seven.Business`
- API：`[Authorize]` + `[Permission("Demo.Search")]`；可选 `[RequiresFeature]`

或使用 **Builder** 生成 CRUD（需 `Features.Builder=true`）。

## 统一响应

所有 API 返回 `WebResponseContent`：

```json
{ "status": true, "message": "操作成功", "data": {}, "code": null }
```

## 缓存 / 密码

- 缓存：`ICacheService`；写后可用延迟双删
- 密码：仅 `IPasswordHasher`（BCrypt），禁止明文/对称可逆存储

## 中间件顺序（摘要）

Exception → TraceId → RequestLog → IpWhitelist → Idempotency(可选) → Compression → RateLimiter → AuthN → AuthZ → 租户上下文 → Controllers / Hubs

## 日志

系统里有两套日志，用途不同：

### 1. 业务/审计日志（`Sys_Log`，页面可查）

| 项 | 位置 |
|----|------|
| 前端 | **系统管理 → 日志管理**，路由 `/Sys_Log`，页面 `Seven.Vue3/src/views/system/Sys_Log.vue` |
| API | `POST /api/Sys_Log/getPageData`（权限 `Sys_Log.Search`） |
| 服务 | `SysLogService`（`Seven.Infrastructure/Services/SystemServices.cs`） |
| 实体/表 | `Sys_Log`（`Seven.Domain/Entities/System`） |
| 写入来源 | 登录等业务写入；开启 `Features.AuditInterceptor` 时由 `AuditSaveChangesInterceptor` 记录实体字段变更 |

### 2. 运行时日志（Serilog）

| 项 | 位置 |
|----|------|
| 配置 | `Seven.WebApi/Program.cs`：`WriteTo.Console` + `WriteTo.File("logs/seven-.log", rollingInterval: Day)` |
| 文件目录 | 一般为 `Seven.Net8/Seven.WebApi/logs/seven-YYYYMMDD.log`（相对 API 进程工作目录） |
| 控制台 | `dotnet run --project Seven.WebApi` 的终端输出 |

Docker 部署时文件在容器内工作目录的 `logs/`；可用 `docker compose logs seven-api` 看控制台流。
