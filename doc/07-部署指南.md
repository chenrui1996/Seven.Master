# 部署指南

## Docker Compose 一键部署

项目根目录 `Seven.Master/docker-compose.yml` 包含：

- **seven-api**：ASP.NET Core Web API
- **mysql**：MySQL 8
- **redis**：Redis 7
- **rabbitmq**：RabbitMQ 3（含管理界面 15672）
- **minio**：MinIO 对象存储

### 启动

```bash
cd Seven.Master
docker compose up -d
```

### 访问

| 服务 | 地址 |
|------|------|
| API | http://localhost:5000 |
| Swagger | http://localhost:5000/swagger |
| MinIO Console | http://localhost:9001 (minioadmin/minioadmin) |
| RabbitMQ 管理 | http://localhost:15672 (guest/guest) |

## 环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| Database__Provider | MySql/SqlServer/PgSql | MySql |
| Database__ConnectionString | 数据库连接串 | 见 compose |
| Database__MigrateOnStartup | 启动时是否自动迁移 | **生产 false**；开发 true |
| Cache__Provider | Memory/Redis | Redis |
| Cache__RedisConnectionString | Redis 连接 | redis:6379 |
| MessageQueue__Provider | None/RabbitMQ | RabbitMQ |
| MessageQueue__RabbitMq__Host | RabbitMQ 主机 | rabbitmq |
| Jwt__Secret | JWT 密钥 | 生产环境必须修改 |
| MinIO__Endpoint | MinIO 地址 | minio:9000 |
| Features__WorkFlow 等 | 功能开关（见 [14-功能开关](./14-功能开关.md)） | 默认偏简单 |
| Features__HotStore | 热数据通道 | false |
| HotStore__Provider | Memory/Redis | Memory |
| HotStore__RedisConnectionString | 热层 Redis（可与 Cache 共用） | — |
| Features__DeviceComm | 设备通讯（Step7/Modbus TCP） | false |
| DeviceComm__RuleScanIntervalMs | 规则扫描节拍 ms | 200 |
| DeviceComm__Reconnect__IntervalMs | 自动重连初始间隔 | 5000 |
| DeviceComm__AlarmCodeDisconnect | 断连告警码 | DEV001 |

## 数据库迁移

由配置 `Database:MigrateOnStartup` 控制：

| 环境 | 推荐值 | 说明 |
|------|--------|------|
| Development | `true` | 本地启动自动 `MigrateAsync()` |
| Production | `false` | **默认关闭**；发布前在流水线执行迁移 |

生产手动/流水线：

```bash
cd Seven.Master/Seven.Net8
dotnet tool restore
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

种子数据（报警码、主子表 Demo 等）仍由启动时的 `DbSeeder` 幂等写入，与是否迁移无关。

## 日志查看（部署环境）

| 类型 | 方式 |
|------|------|
| 业务/审计（`Sys_Log`） | 浏览器打开系统 → **系统管理 → 日志管理** |
| API 控制台流 | `docker compose logs -f seven-api`（服务名以 compose 为准） |
| Serilog 文件 | 容器/主机上 API 工作目录下 `logs/seven-*.log`；持久化需挂载该目录 |

本地开发查看说明见 [01-快速开始 §6](./01-快速开始.md#6-如何查看日志)。

## 生产建议

1. 修改 JWT Secret 和数据库密码
2. 保持 `Database:MigrateOnStartup=false`，发布前流水线执行 `dotnet ef database update`
3. 启用 HTTPS（Nginx 反向代理）
4. 按场景配置 `Features`（简单项目勿全开）
5. Redis 持久化（若使用 Redis 缓存）；按需挂载 `logs/` 目录
6. 数据库定期备份

## 手动部署

### 后端

```bash
cd Seven.Net8/Seven.WebApi
dotnet publish -c Release -o ./publish
# 部署 publish 目录到服务器，配置 appsettings.Production.json
```

### 前端

```bash
cd Seven.Vue3
npm run build
# 将 dist/ 部署到 Nginx 静态目录
```

### Nginx 示例

```nginx
server {
    listen 80;
    location / {
        root /var/www/seven/dist;
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:5000;
    }
    location /hub/ {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```
