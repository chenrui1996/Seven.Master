# 权限与菜单

## RBAC 模型

```
用户 (Sys_User) ──N:1──> 角色 (Sys_Role)
角色 (Sys_Role) ──N:N──> 菜单/按钮 (Sys_Menu.Auth)
用户 (Sys_User) ──N:N──> 部门 (Sys_Department)
```

## 菜单类型

- **目录**：ParentId 指向父菜单，Url 为空（如「系统管理」）
- **页面**：Url 指向 Vue 路由，如 `/Sys_User`
- **按钮**：Auth 字段存储权限标识，如 `Search,Add,Update,Delete,Import,Export`

## 菜单树

种子数据中「系统管理」为父节点，各子菜单 `ParentId` 指向父节点。后端 `getMenu` 会自动补全祖先节点；前端 [`utils/menuTree.ts`](../Seven.Vue3/src/utils/menuTree.ts) 将扁平列表构建为 `children` 树供侧边栏渲染。

**已有数据库**：若菜单仍为扁平结构，可执行 [`scripts/fix-menu-parent.sql`](../scripts/fix-menu-parent.sql)，然后 admin 重新登录。

## 动态菜单 API

`GET /api/Sys_Menu/getMenu`

返回当前用户角色可见的菜单（含祖先目录），前端构建树后生成侧边栏和动态路由。

## 前端页面

| 页面 | 路径 | 功能 |
|------|------|------|
| 用户管理 | `/Sys_User` | CRUD、改密、`v-permission` 按钮 |
| 角色管理 | `/Sys_Role` | CRUD、菜单权限分配 |
| 菜单管理 | `/Sys_Menu` | 左树右表单 CRUD |
| 部门管理 | `/Sys_Department` | 左树右表单 CRUD |

## 按钮权限

角色授权时勾选菜单及按钮权限，存储在 `Sys_RoleAuth.AuthValue`（逗号分隔动作，如 `Search,Add`）。

登录时展开为权限码：`{TableName}.{Action}`（如 `Device.Add`）。**仅使用 AuthValue**，不会回退到菜单上的全部 Auth。

前端控制方式：

- 生成页推荐：`v-if="userStore.hasPermission('Device.Add')"`（响应式，改权后立即更新）
- 其它页：`v-permission="'Sys_User.Add'"`（`display: none !important`，并监听 permissions 变化）

进入系统时会请求 `GET /api/Auth/permissions` 刷新权限；若保存的是**当前登录角色**的授权，前端会立刻 `refreshPermissions()`。其它账号需重新登录。

```typescript
permissions: ['Sys_User.Search', 'Sys_User.Add', ...]
```

## 接口权限

- 登录接口：`[AllowAnonymous]`
- 管理接口：`[Authorize]`
- 权限字符串格式：`{TableName}.{Action}`，由 `AuthService.GetPermissionsAsync` / `GET /api/Auth/permissions` 生成

## 配置步骤

1. **菜单管理**：维护菜单树与 Auth 定义（`TableName` + `Auth`）
2. **角色管理**：创建角色 →「权限」分配菜单与按钮动作
3. **用户管理**：为用户分配角色
4. 修改权限后：当前登录角色会自动刷新；其它用户需重新登录

### 导入 / 导出 / 自定义按钮如何出现在授权里

链路是：**菜单 Auth 勾选 → 存入 `Sys_Menu.Auth` → 角色授权弹窗按该菜单 Auth 列出动作 → 勾选后写入 `Sys_RoleAuth.AuthValue` → 前端变成 `{表名}.{动作}`**。

对任意业务菜单启用导入导出（示例）：
1. **菜单管理** → 选中目标菜单 → 按钮权限勾选 `Import`、`Export` → **保存**
2. **角色管理** → 权限 → 该菜单一行会出现「导入」「导出」→ 勾选 → **保存权限**
3. 刷新页面或重新登录后，设备页的导入/导出按钮才会显示（需具备 `Device.Import` / `Device.Export`）

扩展自定义按钮同理：扩展里写 `permission: 'Device.Xxx'`，则菜单 Auth 必须包含动作码 `Xxx`（若菜单页可选列表没有该码，需在 [`Sys_Menu.vue`](../Seven.Vue3/src/views/system/Sys_Menu.vue) 的 `authOptions` 中追加，或直接把 `Auth` 字段写成含该码的逗号串）。角色授权里勾选后，权限码为 `Device.Xxx`。

菜单页可选动作目前包括：`Search,Add,Update,Delete,Import,Export,Upload,Audit,Acknowledge,Clear,Raise`。角色弹窗中文名来自后端 `ActionLabels`。

**设备通讯菜单**（需 `Features.DeviceComm=true`，见 [16](./16-设备通讯DeviceComm.md)）：种子会幂等创建顶级目录「设备通讯」（`TableName=DeviceCommFolder`）及子项 `CommConnection` / `CommPoint` / `CommRule` / `DeviceComm`（运行态）。前端按 TableName 过滤；角色需勾选对应 Auth（如 `CommConnection.Search`、`DeviceComm.Update`）后菜单与按钮才可用。若旧库菜单仍在「系统管理」下，重启种子会自动迁移到该目录。
