# 权限与菜单

## RBAC 模型

```
用户 (Sys_User) ──N:1──> 角色 (Sys_Role)
角色 (Sys_Role) ──N:N──> 菜单/按钮 (Sys_Menu.Auth)
用户 (Sys_User) ──N:N──> 部门 (Sys_Department)
```

## 菜单类型

- **目录**：ParentId 指向父菜单，Url 为空
- **页面**：Url 指向 Vue 组件路径，如 `/Sys_User`
- **按钮**：Auth 字段存储权限标识，如 `Search,Add,Update,Delete`

## 动态菜单 API

`GET /api/Sys_Menu/getMenu`

返回当前用户角色可见的菜单树，前端据此生成侧边栏和路由。

## 按钮权限

角色授权时勾选菜单下的按钮权限，存储在 `Sys_RoleAuth` 表。

前端通过 `v-permission` 指令控制按钮显示：

```javascript
// stores/user.ts 中存储 permissions 数组
permissions: ['Sys_User.Search', 'Sys_User.Add', ...]
```

## 接口权限

后端 `[Authorize]` + 自定义 `PermissionFilter`（可选 Policy）：

- 登录接口：`[AllowAnonymous]`
- 管理接口：`[Authorize]`
- 细粒度：检查 JWT Claims 中的 RoleId 与菜单 Auth

## 数据权限（扩展）

架构设计支持 5 种数据权限，Seven 预留 `DeptIds` 字段，可按部门过滤数据。

## 配置步骤

1. **菜单管理**：系统管理 → 菜单配置，维护菜单树
2. **角色管理**：创建角色，分配菜单和按钮权限
3. **用户管理**：为用户分配角色和部门
