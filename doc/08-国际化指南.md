# 国际化（i18n）指南

Seven.Vue3 使用 [vue-i18n v11](https://vue-i18n.intlify.dev/) + JSON 语言包，与 Element Plus 内置语言包联动。默认语言为 **简体中文（zh-CN）**。

## 目录结构

```
Seven.Vue3/
├── src/
│   ├── locales/
│   │   ├── index.ts              # i18n 实例、SUPPORT_LOCALES 注册
│   │   ├── element-plus.ts       # Element Plus 语言包映射
│   │   └── lang/
│   │       ├── zh-CN.json        # 源语言（新增键先写这里）
│   │       ├── en-US.json
│   │       └── ja-JP.json
│   ├── stores/locale.ts          # 语言切换 + localStorage 持久化
│   ├── composables/useMenuLabel.ts  # 后端菜单名 → menu.{name} 翻译
│   └── components/LocaleSwitch.vue  # 顶栏/登录页语言切换
└── scripts/i18n-auto-translate.mjs  # 自动翻译脚本
```

## 如何配置翻译

### 1. 在页面中使用

Composition API（推荐）：

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <h1>{{ t('home.title') }}</h1>
  <p>{{ t('home.permissionsUnit', { count: 12 }) }}</p>
</template>
```

模板中也可直接使用 `$t('common.add')`（已开启 `globalInjection`）。

### 2. 维护语言包 JSON

所有文案键以 **zh-CN.json 为唯一源**。命名约定：

| 前缀 | 用途 |
|------|------|
| `common.*` | 通用按钮、状态 |
| `layout.*` | 布局、侧栏、顶栏 |
| `login.*` / `home.*` | 页面级文案 |
| `menu.*` | 后端返回的中文菜单名映射 |
| `locale.*` | 语言切换下拉显示名 |

示例（`src/locales/lang/zh-CN.json`）：

```json
{
  "common": {
    "add": "新增"
  },
  "menu": {
    "用户管理": "用户管理"
  }
}
```

对应英文（`en-US.json`）：

```json
{
  "common": {
    "add": "Add"
  },
  "menu": {
    "用户管理": "Users"
  }
}
```

### 3. 后端菜单翻译

后端 `Sys_Menu` 返回的 `menuName` 为中文。前端通过 `useMenuLabel()` 查找 `menu.{menuName}` 键，找不到则显示原文：

```vue
<script setup lang="ts">
import { useMenuLabel } from '@/composables/useMenuLabel'
const { menuLabel } = useMenuLabel()
</script>

<span>{{ menuLabel(menu.menuName) }}</span>
```

新增菜单时，在 **各语言 JSON 的 `menu` 节点** 补充对应键即可。

### 4. Element Plus 联动

`App.vue` 使用 `el-config-provider :locale="localeStore.elementLocale"`，切换语言时表单校验、分页、日期等组件文案会自动切换。

## 如何新增语言

以新增 **韩语（ko-KR）** 为例：

### 步骤 1：复制语言包

```bash
cp src/locales/lang/zh-CN.json src/locales/lang/ko-KR.json
```

将 `ko-KR.json` 内容翻译为韩语（可借助自动翻译脚本，见下文）。

### 步骤 2：注册语言

编辑 `src/locales/index.ts`：

```ts
import koKR from './lang/ko-KR.json'

export const SUPPORT_LOCALES = [
  // ...existing
  { code: 'ko-KR', elName: 'ko', nameKey: 'locale.ko-KR' },
] as const

// messages 中增加
messages: {
  // ...
  'ko-KR': koKR,
}
```

### 步骤 3：Element Plus 语言包

编辑 `src/locales/element-plus.ts`，在 `localeMap` 中增加：

```ts
import ko from 'element-plus/es/locale/lang/ko'

const localeMap = {
  // ...
  'ko-KR': ko,
}
```

### 步骤 4：显示名称

在各语言 JSON 的 `locale` 节点增加：

```json
"locale": {
  "ko-KR": "한국어"
}
```

### 步骤 5：自动翻译脚本（可选）

在 `scripts/i18n-auto-translate.mjs` 的 `langMap` 中增加 `'ko-KR': 'ko'`，然后执行：

```bash
npm run i18n:translate -- --target ko-KR
```

或在 `package.json` 增加专用脚本：

```json
"i18n:translate:ko": "node scripts/i18n-auto-translate.mjs --target ko-KR"
```

完成后重启开发服务器，顶栏 **LocaleSwitch** 下拉中会出现新语言。

## 自动翻译

项目提供开发态脚本 `scripts/i18n-auto-translate.mjs`，以 **zh-CN.json 为源**，检测目标语言缺失的键并调用机器翻译 API 补齐。

### 命令

```bash
# 仅列出 en-US 相对 zh-CN 的缺失键（不写入文件）
npm run i18n:missing

# 自动翻译并写入 en-US.json
npm run i18n:translate

# 自动翻译日语
npm run i18n:translate:ja
```

### 环境变量（任选其一）

| 变量 | 说明 |
|------|------|
| `DEEPL_AUTH_KEY` | [DeepL API](https://www.deepl.com/pro-api)（推荐，质量高） |
| `GOOGLE_API_KEY` | Google Cloud Translation API |
| `LIBRETRANSLATE_URL` | 自建或公共 [LibreTranslate](https://libretranslate.com) 端点 |

PowerShell 示例：

```powershell
$env:DEEPL_AUTH_KEY = "your-key"
npm run i18n:translate
```

### 行为说明

- **无 API Key**：只打印缺失键列表，**不会覆盖**已有翻译。
- **有 API Key**：仅翻译缺失键，已有键保持不变。
- **占位符**：含 `{name}`、`{count}` 等 vue-i18n 插值的字符串会原样保留结构。
- **生产环境**：仍建议人工审校 JSON；自动翻译适合开发阶段快速补齐。

### CI 集成建议

可在 PR 检查中加入：

```bash
npm run i18n:missing
```

若输出非空，提示开发者补充翻译或运行 `i18n:translate`。

## 用户切换与持久化

- 组件：`LocaleSwitch`（登录页右上角、主布局顶栏）
- Store：`useLocaleStore().setLocale('en-US')`
- 持久化：Pinia `persist: true`，键名 `locale`，写入 `localStorage`
- 首屏：`index.html` 内联脚本读取 `locale`，设置 `<html lang>`，避免闪烁

## 新增页面 Checklist

1. 文案写入 `zh-CN.json`（及同步其他语言）
2. 页面使用 `useI18n()` / `$t()`
3. 新菜单名加入各语言 `menu` 节点
4. 运行 `npm run i18n:missing` 确认无遗漏
5. `npm run build` 验证编译
