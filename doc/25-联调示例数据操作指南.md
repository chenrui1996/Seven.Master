## 3. 手工逐步示例（与脚本等价）

### 3.1 仓库与库位

1. **仓储WMS → 仓库**：新增 `RETAIN_WH`，`EnabledPackIds=stacker,fourway`。  
2. **库区** `COV.Z01`（pack=`stacker`）。  
3. **层** `Fw.L01`（pack=`fourway`）。  
4. **巷道** `Stk.A1`、`Fw.A1`。  
5. **库位**（`packId` 或 `Stk.`/`Fw.` 前缀二选一，否则拒批）：

| Code | Pack | 说明 |
|------|------|------|
| `Stk.RECV-01` | stacker | 立库收货 |
| `Stk.LOC-A1-01` | stacker | 立库货位，`Aisle=A1` |
| `Fw.RECV-01` / `Fw.LOC-A1-01` | fourway | 四向收货/货位 |
| `Stk.HO-01` | stacker | 交接位（`IsHandover`） |

6. **交接链**：FromPack=`stacker` → Location=`Stk.HO-01` → ToPack=`fourway`。  
7. **容器类型**：`COV-PALLET`。

### 3.2 立库 / 四向主数据

- 立库：`Stk_AssignmentPolicy(A1→EP-A1)`、`Stk_RequestPoint(RP_IN_01)`、`Stk_Route`、`Stk_LocationProfile`、`Stk_DeviceCoder`。  
- 四向：激活 `Fw_MapVersion` + `Fw_Node`/`Fw_Route`、`Fw_LayerPolicy`/`Fw_AislePolicy`、`RP_FW_AISLE`、`Fw_ParkingLedger`、`Fw_HoistDevice(H1)` + `Fw_HoistLayerPoint`。

### 3.3 业务单据示例（本次 Run）

| 类型 | 单号样例 | 结果 |
|------|----------|------|
| 入库（平库同址） | `RETAIN-IN-20260913-195525-*` | Completed + 库存 |
| 入库（立库/四向异址） | `COV-IN-STK-*` / `COV-IN-FW-*` | 建 Bus Leg；可用 Trigger / Ops 强制完成推进 |
| 出库 | `COV-OUT-*` / `RETAIN-OUT-*` | 可 `generatePicks` |
| 盘点 | `RETAIN-CC-*` | 录数确认调账 |
| 调拨 | `COV-XFER-*` | approve → complete |

仿真推进：

```http
POST /api/Wcs/Triggers/destination-request
{ "containerCode":"…", "sourcePointCode":"RP_IN_01", "height":1, "weight":10, "checkResult":"OK" }

POST /api/Wcs/Triggers/segment-feedback
{ "containerCode":"…", "segmentPointCode":"EP-A1", "feedbackCode":"OK", "legId":"<leg-guid>" }
```

运维强制完成（任务卡住时）：

```http
POST /api/Wcs/Stacker/Ops/force-complete   { "targetType":"putAway|retrieval|device", "id":"<guid>" }
POST /api/Wcs/FourWay/Ops/force-complete   { "targetType":"putAway|shuttle|hoist|…", "id":"<guid>" }
```

## 5. 常见坑（联调踩过）

1. 库位无 `Stk.`/`Fw.` 前缀且无 `packId` → 拒批。  
2. `control-mode.mode` 传字符串会 400，用数值枚举。  
3. `force-complete` 字段为 `targetType`。  
4. 单据 `add` 若返回 JSON 环 500，实体可能已写入——按单号回查（代码已修 IgnoreCycles，**重启 WebApi** 后更干净）。  
5. 异址组盘若报 `no pack or handover for route`：检查 `EnabledPackIds`、交接链与两端 Pack。  
6. DotNet 测试请用 `-o` 独立输出目录，避免锁正在运行的 WebApi。
