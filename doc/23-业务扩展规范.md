# 23 · 业务扩展规范（Seven.Business / Biz_）

本文约定：**当前仓库内已落地的 WMS/WCS/系统能力为「标准方案」**；项目侧扩展（新出入库单据类型、新在库处理单据与逻辑等）优先走本规范，避免继续膨胀 `Infrastructure/Wms` 与 `Entities/Wms` 核心包。

相关：[02-后端开发指南](./02-后端开发指南.md) · [19-WMS与WCS包](./19-WMS与WCS包.md) · [20-WMS与WCS实现说明](./20-WMS与WCS实现说明.md) · [22-异常码规范](./22-异常码规范.md)

---

## 1. 原则

| 原则 | 说明 |
|------|------|
| **标准不改内核** | `Wms_` 入/出库、拣选、库存、`Bus_`/`Stk_`/`Fw_` 等视为产品标准能力；扩展优先**组合调用**，不随意改核心表结构与主流程语义 |
| **扩展落点固定** | 新业务逻辑 → `Seven.Business`；新实体/表 → `Seven.Domain/Entities/Business` + 表前缀 `Biz_` |
| **契约仍在 Application** | 接口与 DTO 放 `Seven.Application`；WebApi 只做薄 Controller |
| **抛错带码** | 扩展逻辑统一 `AppException` / 领域异常 + 业务码，见 [22](./22-异常码规范.md) |
| **菜单自选** | 扩展单据的 Vue 菜单可挂任意一级轨或中层目录，不强制「业务扩展」轨 |
| **可配 PDA** | 扩展可通过 `IPdaMenuContributor` + `/api/pda/biz/*` + `Seven.App` 页配套移动端 |
| **钩子扩展标准流** | 入出库审核、待办过滤等走 `IWmsExtensionHooks`，禁止在内核里堆项目 `if` |

```
推荐依赖（扩展场景）:

Seven.WebApi Controllers / PDA
      ↓
Seven.Application (IXxxService / Hooks / PdaContributor)
      ↓
Seven.Business (领域编排 + 钩子实现 + PDA 菜单贡献)
      ↓ 调用 / 被标准内核回调
Seven.Infrastructure (IStockService / IPickingService / PdaService…)
      ↓
Seven.Domain Entities/Business (Biz_* 表)
```

---

## 2. 什么算「标准」、什么算「扩展」

### 2.1 标准方案（已落地，默认维护于此）

| 能力 | 典型位置 |
|------|----------|
| WMS 主数据 / 库存 / 入出库 / 拣选 / 盘点 | `Entities/Wms`、`Infrastructure/Wms`、`TablePrefixes.Wms` |
| 编排总线 | `Entities/Bus`、`Infrastructure/Wcs/Bus` |
| 堆垛 / 四向 / 外部 WCS / SCADA / 仿真 | `Stk_`/`Fw_`/`Ext_`/`Scd_`/`Sim_` 包路径 |
| 系统管理、工作流引擎骨架 | `Infrastructure/Services`、`Seven.Business/WorkFlowService` |
| PDA 标准宫格 | 收货 / 上架 / 拣选 / 盘点（`PdaService` 内置） |

前端：标准 CrudPanel + `extension/Wms/*`；菜单由 `DbSeeder` 种子。

### 2.2 推荐作为扩展（集中到 Business）

示例（非穷尽）：

- 新**出入库单据类型**（销售退、调拨单、质检出库等）——若不能用现有 `WmsOrderType` + 标准入出库表达
- 新**在库处理单据**（移库单、拆合托、冻结/解冻、报废、补货任务等）
- 项目专属审批编排、对接 ERP 的中间单据
- 样板业务（现有 `TransferOrder` 仓内调拨即此路径）

**优先组合标准能力**：扩展服务内调用 `IStockService.Book/Receive/Ship/ConfirmPick`、`IPickingService`、`ITransportOrderRequest` 等，**禁止**复制第二套库存账本。

## 3. 落点清单（Checklist）

新增一类扩展单据时，按序落地：

| # | 动作 | 位置 |
|---|------|------|
| 1 | 实体 `XxxOrder` / `XxxOrderLine`… | `Seven.Domain/Entities/Business/` |
| 2 | 表名 `Biz_Xxx…`，配置 `ToTable(TablePrefixes.Biz + "…")` | `Infrastructure/Persistence/Configurations/Business/` |
| 3 | `DbSet` + EF Migration | `SevenDbContext` + Migrations |
| 4 | 接口 + DTO | `Seven.Application`（建议子目录 `Business/`） |
| 5 | **服务实现** | **`Seven.Business/`**，`AddSevenBusiness()` 注册 |
| 6 | API | `Seven.WebApi/Controllers/Business/` |
| 7 | 异常码 | `ExceptionCodes.Biz` + [22](./22-异常码规范.md) |
| 8 | **菜单（自选挂载）** / 权限 / Vue 页 | Seeder + `views/Business/` + `extension/Business/` + `menu.*` i18n |
| 9 | **（可选）PDA** | `IPdaMenuContributor` + `/api/pda/biz/...` + `Seven.App/pages/...` + `pages.json` |
| 10 | **（可选）标准流钩子** | 实现/替换 `IWmsExtensionHooks` |
| 11 | 测试 | `Seven.Tests` |

## 4. 表命名与实体规范（Biz_）

### 4.1 前缀权威

常量：`Seven.Domain/Wcs/TablePrefixes.cs` → `TablePrefixes.Biz`（`"Biz_"`）。

| 规则 | 正确 | 错误 |
|------|------|------|
| 物理表名 | `Biz_TransferOrder` | `TransferOrder`、`Wms_TransferOrder` |
| 实体类名 | `TransferOrder`（`Entities.Business`） | 表名勿丢 `Biz_` |
| EF 配置 | `builder.ToTable(TablePrefixes.Biz + "TransferOrder")` | 散落硬编码 |

现有样例：`TransferOrder` / `TransferOrderLine` → `Biz_TransferOrder` / `Biz_TransferOrderLine`。

### 4.2 字段与单据习惯

- 继承 `BaseEntity`；头：`OrderNo`、`Status`；行：`LineNo`、`MaterialCode`、`Qty`、库位/容器
- **库存变更**只通过 `IStockService`

### 4.3 何时仍用 `Wms_`？

仅当能力升格为产品标准并经评审后，才迁入 `Entities/Wms`。其它前缀见 [19 §2](./19-WMS与WCS包.md)。

## 5. Seven.Business 编码约定

```csharp
services.AddScoped<ITransferOrderService, TransferOrderService>();
services.AddScoped<IWmsExtensionHooks, NoOpWmsExtensionHooks>(); // 或项目复合实现
services.AddScoped<IPdaMenuContributor, TransferOrderPdaMenuContributor>();
```

- 一个业务域一组 `*Service.cs`；事务用 `WmsTransaction` / `BeginTransactionAsync`
- **不要**在 Business 直接依赖 PLC/具体 WCS 包；走 Bus / Application 抽象

## 6. 前端菜单（自选挂载）

- 页面：`Seven.Vue3/src/views/Business/`，扩展脚本 `extension/Business/`
- 路由 Url 建议 `/Business/TransferOrder`；`TableName` 与权限前缀全项目统一（样板用 `TransferOrder`）
- **挂载点可自选**（改 Seeder 中 leaf 的 `Parent` 即可）：

| 挂载 | 说明 |
|------|------|
| 独立一级轨 `BizFolder` | 样板默认「业务扩展」 |
| `仓储WMS` 中层（如单据作业） | 与标准入出库并列 |
| `立库WCS` / `四向车WCS` 中层 | 设备侧相关扩展 |
| `执行运维` | 运维类工具页 |

必填：`Auth`、`menu.{中文名}` 三语、图标（`menuIcons.ts` 可选）。样板种子：`DbSeeder.SeedBizMenusAsync`（注释说明如何改 Parent）。

## 7. 配套 PDA

标准 PDA 宫格由 `PdaService.GetMenu()` 提供；扩展项通过 **`IPdaMenuContributor`** 追加，与标准项合并返回。

| 项 | 约定 |
|----|------|
| 贡献器 | `Seven.Business` 实现 `IPdaMenuContributor.GetExtraMenus()` |
| API | 建议 `/api/pda/biz/{domain}/...`（样板：调拨 `pending` / `complete/{id}`） |
| App 页 | `Seven.App/src/pages/{domain}/index.vue`，并写入 `pages.json` |
| 客户端 API | `Seven.App/src/api/pda.ts` |

样板：仓内调拨 → 菜单 code `transfer` → `/pages/transfer/index` → 完成已审调拨单。

## 8. 标准流程钩子（`IWmsExtensionHooks`）

内核在关键节点回调钩子；**默认** `NoOpWmsExtensionHooks`（无操作）。项目在 `Seven.Business` 实现并在 `AddSevenBusiness` 替换注册。

| 钩子 | 触发点 | 典型用途 |
|------|--------|----------|
| `BeforeInboundApprove` / `AfterInboundApprove` | 入库审核前后 | 校验、写扩展单、通知 |
| `BeforeOutboundApprove` / `AfterOutboundApprove` | 出库审核前后（含生成拣选之后为 After） | 同上 |
| `FilterPendingPicking` | `PickingService.ListPendingAsync`、PDA 待拣选 | 按仓/客户过滤任务 |
| `FilterPendingInbound` | PDA 待收货列表 | 过滤可见入库单 |

**禁止**：钩子内直接改 `Wms_Stock.Qty`；应调用 `IStockService`。  
**禁止**：在 `OutboundOrderService` 内写死项目分支代替钩子。

---

## 9. 反模式（禁止）

1. 在 `Infrastructure/Wms` 为每个客户复制 `OutboundOrderService2`
2. 扩展表无前缀或误用 `Wms_`/`Stk_`
3. 手写改库存绕过 `IStockService`（含钩子内）
4. Controller 堆业务；异常无 `Code`
5. 再建第二套库位主数据
6. 改内核 `if (customer==…)` 代替 `IWmsExtensionHooks`

## 10. 最小示例骨架（仓内调拨）

```
Entities/Business/TransferOrder.cs
Application/Business/ITransferOrderService.cs + IWmsExtensionHooks.cs
Business/TransferOrderService.cs
Business/NoOpWmsExtensionHooks.cs
Business/TransferOrderPdaMenuContributor.cs
WebApi Controllers/Business/TransferOrdersController.cs
WebApi Controllers/Pda/TransferOrderPdaController.cs   → /api/pda/biz/transfer/*
Vue: views/Business/TransferOrder.vue
App: pages/transfer/index.vue

```

**库存注意**：审核 `Book` 后完成须用 `ConfirmPick` + `Receive`（勿对已预约行直接 `Ship`）。

### 本地点通

```powershell
cd Seven.Master\Seven.Net8
dotnet test Seven.Tests\Seven.Tests.csproj --filter "FullyQualifiedName~TransferOrder|FullyQualifiedName~Pda|FullyQualifiedName~WmsExtensionHooks"
# 重启 WebApi；Vue「业务扩展→仓内调拨」；PDA 宫格出现「仓内调拨」
```

### 复制下一张单时改什么

1. 实体 / `Biz_` 表名 / 服务 / 权限前缀  
2. 菜单 Parent（自选挂载）+ i18n  
3. 如需 PDA：Contributor + `/api/pda/biz/...` + App 页  
4. 如需介入标准入出库/拣选：实现 `IWmsExtensionHooks`（可 Composite 多实现）  
5. 库存仍只组合 `IStockService`
