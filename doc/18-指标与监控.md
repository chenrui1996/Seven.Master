# 指标与监控（Prometheus / Grafana）

Seven 用 **Prometheus** 采集时间序列，用 **Grafana** 看图。与 [17-健康检查看板](./17-健康检查看板.md) 分工：

| | HealthChecks (`/health`、`/health-ui`) | 本栈 (`/metrics` + Grafana) |
|--|--|--|
| 用途 | 依赖是否健康（阈值） | CPU / 内存 / IO / HTTP 趋势 |
| 形态 | 绿黄红状态 | 曲线与速率 |

实现：`prometheus-net.AspNetCore`（`MetricsExtensions`）、`deploy/monitoring/`、`docker-compose.yml`。

---

## 1. 启动与访问

```bash
cd Seven.Master
docker compose up -d
```

| 服务 | 地址 | 说明 |
|------|------|------|
| Grafana | http://localhost:3000 | 账号 `admin` / `admin`；看板 **Seven Overview**（文件夹 Seven） |
| Prometheus | http://localhost:9090 | Targets 应含 `seven-api`、`cadvisor`、`node-exporter` |
| API metrics | http://localhost:5000/metrics | Prometheus 文本；匿名 |
| cAdvisor | http://localhost:8081 | 容器资源页（可选） |
| node-exporter | http://localhost:9100/metrics | 主机指标原始端点 |

预置看板含：API 请求速率、进程内存、容器 CPU/内存/磁盘 IO、主机 CPU%。

---

## 2. 本机 `dotnet run` 时

Compose 默认 scrape 的是容器内 `seven-api:8080`。若只在本机跑 API（如 `http://localhost:5000`），可临时改 `deploy/monitoring/prometheus.yml`：

```yaml
  - job_name: seven-api
    metrics_path: /metrics
    static_configs:
      - targets: ["host.docker.internal:5000"]
```

然后重启 Prometheus：`docker compose up -d prometheus`。

---

## 3. 安全与平台说明

- 本栈面向**本地 / 内网**。勿把 `/metrics`、Grafana、cAdvisor、Prometheus 裸暴露公网。
- **Windows Docker Desktop** 上 cAdvisor / node-exporter 指标可能不全；完整主机/容器 IO 建议 Linux 或 WSL2 后端。
- cAdvisor 镜像来自 `gcr.io`，拉取较慢时可换镜像加速或等价镜像，保持端口 `8081:8080`。
