# 安全与数据权限

总开关见 [14-功能开关](./14-功能开关.md)。下列细节节与 `Features.*` 为 **AND**。

## 验证码

- `GET /api/Captcha/create` 返回 `{ key, code }`
- 登录请求体字段：`uuid`（key）、`verificationCode`（code）
- 生效条件：`Features:Captcha=true` **且** `Security:CaptchaEnabled=true`
- 前端仅在 Features.Captcha 为 true 时显示验证码区

## 限流

- 由 `Features:RateLimit` 控制（false 时额度极大，等同关闭）
- 全局：每 IP 每分钟 300 次
- 登录策略 `login`：每 IP 每分钟 `Security:LoginPermitLimit` 次

## 防重复提交

- `Features:Idempotency=true` 时挂载中间件
- 请求头 `X-Idempotency-Key`，短时缓存拒绝重复 POST/PUT/DELETE

## API 权限

- 特性 `[Permission("Device.Add")]` → Policy `perm:Device.Add`
- 超级管理员 `RoleId=1` 放行
- 示例已挂到 `DeviceController`

## 数据权限

`Features:DataScope=false` 时一律视为「全部」。开启后按角色字段 `DataScope`：

| 值 | 含义 |
|----|------|
| 0 | 全部 |
| 1 | 本部门 |
| 2 | 本部门及下级 |
| 3 | 仅本人 |

`SysDeviceService` 已按 `CreateId` 过滤示范。

列表查询可注入 `IDataScopeService`：

- `GetAllowedUserIdsAsync`：空集合表示全部（超管 / DataScope.All）
- `FilterByCreateIds` / `ApplyCreateIdScopeAsync`：按 `CreateId` 过滤 `BaseEntity`
- `FilterUsersByAllowedIds`：`Sys_User` 按部门范围过滤用户 Id
- `FilterLogsByUserIds`：`Sys_Log` 按 `User_Id` 过滤
- `CrudHelper.PaginateWithCreateIdScopeAsync`：组合过滤 + 分页

已应用：`SysUserService`、`SysLogService`、`AlarmService`、`SysSubDeviceService`、`SysDeviceService`。

字段级审计写入 `Sys_Log`（`Features.AuditInterceptor`）。**在界面查看**：系统管理 → 日志管理（`/Sys_Log`）；文件日志见 [01-快速开始 §6](./01-快速开始.md#6-如何查看日志)。

## 多租户

- 生效条件：`Features:Tenant=true` **且** `Tenant:Enabled=true`
- `BaseEntity.TenantId`；生产/K8s 可设 `Features__Tenant=true` + `Tenant__Enabled=true`
- 开启后 `TenantContextInitializer` 设置 `SevenDbContext.TenantFilterEnabled`，按 JWT Claim `TenantId` 隔离数据
- `TenantId = 0` 视为公共数据，所有租户可见
- 种子数据默认租户 `Sys_Tenant`（Code=`default`，Id=1）；admin 及菜单等种子 `TenantId=1`
- 登录响应含 `tenantId`；Token 刷新保留租户 Claim
