# 22 · 异常码规范

业务异常必须带 **Code** + 中文 Message，禁止 `throw new Exception("裸中文")` 无码。生成器与业务代码统一遵循本规范。

相关：[`AppException`](../Seven.Net8/Seven.Domain/Common/AppException.cs)、[`ExceptionHandlingMiddleware`](../Seven.Net8/Seven.Infrastructure/Middleware/SevenMiddleware.cs)、[02-后端开发指南](./02-后端开发指南.md)。

## 1. 响应约定

中间件捕获 `AppException` 后返回（HTTP 默认 400，可按异常覆盖）：

```json
{
  "status": false,
  "code": "WMS.STOCK_INSUFFICIENT",
  "message": "库存不足",
  "traceId": "...",
  "data": null
}
```

未知异常 → HTTP 500 + `SYS.UNHANDLED`。

Controller 内捕获领域异常时也应写入 `WebResponseContent.Error(message, code)`。

## 2. 码段

| 前缀 | 模块 |
|------|------|
| `SYS.*` | 系统 / 未处理 |
| `AUTH.*` | 认证授权 |
| `WMS.*` | 仓储账本与单据 |
| `BUS.*` | 编排总线 |
| `STK.*` | 堆垛机包 |
| `FW.*` | 四向车包 |
| `SIM.*` | 仿真 |
| `BIZ.*` | 业务扩展（Seven.Business / Biz_） |
| `DC.*` | 设备通讯（预留） |

## 3. 首批码表

| Code | 含义 |
|------|------|
| `SYS.UNHANDLED` | 未处理异常 |
| `SYS.VALIDATION` | 入参校验失败 |
| `AUTH.UNAUTHORIZED` | 未登录 |
| `AUTH.FORBIDDEN` | 无权限 |
| `WMS.DOMAIN` | 通用 WMS 领域错误（过渡） |
| `WMS.STOCK_INSUFFICIENT` | 库存不足 |
| `WMS.ORDER_STATUS_ILLEGAL` | 单据状态不允许当前操作 |
| `WMS.ORDER_NOT_FOUND` | 单据不存在 |
| `WMS.QTY_INVALID` | 数量非法 |
| `WMS.LOCATION_REQUIRED` | 缺少库位 |
| `WMS.LOCATION_NOT_FOUND` | 库位不存在 |
| `WMS.LOCATION_LOCKED` | 库位锁定 |
| `WMS.MATERIAL_REQUIRED` | 缺少物料 |
| `WMS.ORDER_NO_REQUIRED` / `ORDER_NO_EXISTS` | 单号 |
| `WMS.LINES_REQUIRED` | 缺少明细行 |
| `WMS.TRANSPORT_PENDING` | 运输中勿手动发运 |
| `WMS.PICKING_NOT_FOUND` | 拣选任务不存在 |
| `WMS.PICKING_STATUS_ILLEGAL` | 拣选状态非法 |
| `BIZ.DOMAIN` | 业务扩展通用错误 |
| `BIZ.ORDER_NOT_FOUND` / `ORDER_STATUS_ILLEGAL` | 扩展单据 |
| `BIZ.ORDER_NO_REQUIRED` / `ORDER_NO_EXISTS` | 扩展单号 |
| `BIZ.LINES_REQUIRED` / `QTY_INVALID` / `MATERIAL_REQUIRED` / `LOCATION_REQUIRED` | 扩展行校验 |
| `BUS.DOMAIN` | 总线领域错误 |
| `SIM.PROMOTE_LOOPBACK` / `FW.PROMOTE_LOOPBACK` | Promote 环回拒绝 |

常量：`Seven.Domain.Common.ExceptionCodes`。

## 4. 抛错示例

```csharp
throw new WmsDomainException(ExceptionCodes.Wms.StockInsufficient, "库存不足");
// 或
throw new AppException(ExceptionCodes.Wms.OrderStatusIllegal, "仅草稿可审核");
```

领域异常应继承 `AppException`（如 `WmsDomainException`、`BusDomainException`）。

## 5. 代码生成约定

- Builder / AI 生成 Service 时：校验失败一律 `AppException`/`WmsDomainException` + `ExceptionCodes`。
- 禁止仅 `throw new Exception(...)` 或无 Code 的中文消息。
- 新增码先补本表与 `ExceptionCodes`，再在业务中引用。
