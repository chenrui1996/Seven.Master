# 生成页自定义按钮开发指南

生成的 CRUD 页面支持**行多选**、**工具栏自定义按钮**与**行内自定义按钮**。业务逻辑写在扩展文件中，**重新生成 Vue 不会覆盖扩展文件**。

列设置、导入导出、查询区、CRUD 钩子、主子表等配置能力见 [12-生成页配置](./12-生成页配置.md)。

## 相关能力（本文）

| 能力 | 说明 |
|------|------|
| 行多选 | 表格左侧复选框，维护 `selectedRows` / `selectedIds` |
| 批量删除 | 工具栏默认按钮，调用 `/api/{表名}/del` |
| 工具栏自定义按钮 | `toolbarButtons`：批量操作、跳转等 |
| 行内自定义按钮 | `rowButtons`：操作列，位于「编辑」与「删除」之间 |
| 扩展弹窗 | `overlay`：挂载非路由弹窗组件 |

## 文件约定

| 路径 | 是否可覆盖 | 说明 |
|------|------------|------|
| `src/views/{文件夹}/{表名}.vue` | 是（生成会覆盖） | 列表 / 表单骨架 |
| `src/extension/{文件夹}/{表名}.ts` | **否** | 自定义按钮与业务扩展 |
| `src/extension/types.ts` | 手写维护 | `PageExtension` / 按钮类型 |
| `src/constants/actionIcons.ts` | 手写维护 | 统一操作图标 `ActionIcons` |

示例（设备页）：

- 页面：`Seven.Vue3/src/views/Board/Device.vue`
- 扩展：`Seven.Vue3/src/extension/Board/Device.ts`

首次「生成 Vue」时，若扩展文件不存在会自动创建空模板；再次生成只覆盖 `.vue`。

## 默认按钮图标

| 按钮 | 图标 |
|------|------|
| 新增 | `ActionIcons.add` |
| 批量删除 | `ActionIcons.batchDelete` |
| 行内编辑 | `ActionIcons.edit` |
| 行内删除 | `ActionIcons.delete` |
| 弹窗确定 | `ActionIcons.save` |

## 扩展 API

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'

const extension: PageExtension = {
  toolbarButtons: [
    // 工具栏
  ],
  rowButtons: [
    // 行内操作列
  ],
}

export default extension
```

### ToolbarButton

| 字段 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 唯一键 |
| `label` | `string` | 按钮文案 |
| `icon` | `Component?` | 图标组件，推荐 `ActionIcons.xxx` |
| `permission` | `string?` | 权限码，如 `Device.Update` |
| `type` | Element Plus 按钮 type | 可选 |
| `requireSelection` | `boolean?` | `true` 时未勾选行则禁用 |
| `onClick` | `(ctx: PageActionContext) => void \| Promise<void>` | 点击处理 |

### RowButton（行内）

| 字段 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 唯一键 |
| `label` | `string` | 按钮文案 |
| `icon` | `Component?` | 图标组件 |
| `permission` | `string?` | 权限码 |
| `type` | link 按钮颜色 | 默认 `primary` |
| `visible` | `(row) => boolean` | 按行控制是否显示 |
| `disabled` | `(row) => boolean` | 按行控制是否禁用 |
| `onClick` | `(ctx: RowActionContext) => void \| Promise<void>` | 点击处理 |

显示位置：操作列中 **编辑之后、删除之前**。操作列宽度会随按钮数量自动加宽。

### PageActionContext / RowActionContext

| 字段 | 说明 |
|------|------|
| `selectedRows` | 勾选行（行内点击时为 `[当前行]`） |
| `selectedIds` | 主键 Id 数组（行内为 `[rowId]`） |
| `row` / `rowId` | **仅 RowActionContext**：当前行对象与主键 |
| `reload` | 重新加载列表 |
| `http` | Axios 封装 |
| `router` | Vue Router |
| `t` | i18n `t` |

### overlay（扩展弹窗）

生成页通过 `<component :is="pageExtension.overlay" />` 挂载扩展弹窗。扩展里打开共享状态即可，无需新路由。

## 示例 1：提交后台处理

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'
import { ElMessage } from 'element-plus'

const extension: PageExtension = {
  toolbarButtons: [
    {
      key: 'customAction',
      label: '自定义处理',
      icon: ActionIcons.sync,
      permission: 'Device.Custom',
      type: 'warning',
      requireSelection: true,
      async onClick(ctx) {
        const res = await ctx.http.post<{ status: boolean; message?: string }>(
          '/api/Device/custom',
          ctx.selectedIds,
        )
        if (res.status) {
          ElMessage.success(ctx.t('common.success'))
          await ctx.reload()
        } else {
          ElMessage.error(res.message || ctx.t('common.operationFailed'))
        }
      },
    },
  ],
}

export default extension
```

## 示例 2：打开自定义弹窗（Device Demo）

Demo 权限（须在菜单 Auth 勾选后，再给角色授权才会显示）：

| 按钮 | 权限码 | 菜单动作 |
|------|--------|----------|
| 工具栏「批量处理」 | `Device.BatchCustom` | `BatchCustom` |
| 行内「处理」 | `Device.RowCustom` | `RowCustom` |

1. **菜单管理** → 设备管理 → 勾选 `BatchCustom`、`RowCustom` → 保存  
2. **角色管理** → 权限 → 勾选「批量处理」「行内处理」→ 保存权限  
3. 刷新页面

| 文件 | 作用 |
|------|------|
| [`extension/Board/Device.ts`](../Seven.Vue3/src/extension/Board/Device.ts) | 按钮 + `overlay: DeviceCustomDialog` |
| [`components/DeviceCustomDialog.vue`](../Seven.Vue3/src/components/DeviceCustomDialog.vue) | 弹窗 |
| [`extension/Board/deviceCustomShared.ts`](../Seven.Vue3/src/extension/Board/deviceCustomShared.ts) | 弹窗开关与数据 |

```ts
import MyDialog from '../../components/MyDialog.vue'
import { openMyDialog } from './myDialogState'

const extension: PageExtension = {
  overlay: MyDialog,
  toolbarButtons: [{
    key: 'batch',
    label: '批量处理',
    permission: 'Device.BatchCustom',
    requireSelection: true,
    onClick(ctx) {
      openMyDialog({ rows: ctx.selectedRows, reload: ctx.reload })
    },
  }],
}
```

## 示例 3：行内自定义按钮

```ts
rowButtons: [
  {
    key: 'rowDetail',
    label: '详情',
    icon: ActionIcons.viewAll,
    permission: 'Device.Search',
    async onClick(ctx) {
      ctx.router.push({
        path: '/DeviceDetail',
        query: { id: String(ctx.rowId) },
      })
    },
  },
]
```

## 自定义按钮如何挂到菜单权限

扩展按钮的 `permission` 格式固定为 **`{表名}.{动作码}`**。

### 在菜单里注册动作码

1. 打开 **系统管理 → 菜单管理**，选中对应页面菜单。
2. 确认 **视图/表名** 与权限前缀一致（如 `Device`）。
3. 在 **按钮权限** 区域：常用动作直接勾选；自定义动作在输入框填写后点 **添加动作**，再勾选。
4. 点 **保存**。

### 在角色授权里勾选

1. **角色管理 → 权限**，找到对应菜单。
2. 勾选动作后 **保存权限**。
3. 当前登录角色会自动刷新；其它账号需重新登录。

> 角色弹窗里的中文名来自后端 `ActionLabels`。可在 `SystemServices.ActionLabels` 中增加映射（可选）。

### 与导入导出的区别

| 类型 | 动作码 | 菜单操作 |
|------|--------|----------|
| 导入 / 导出 | `Import` / `Export` | 勾选预设项即可 |
| 扩展自定义按钮 | 自定，如 `Custom` | 用「添加动作」写入后再勾选 |

## 与代码生成器的关系

- 模板：`Seven.WebApi/Template/VuePage.html`、`VueExtension.ts.html`
- 生成逻辑：`Seven.Builder/BuilderService.CreateVuePageAsync`
- 扩展输出根目录：`Seven.Vue3/src/extension/`

更多生成器说明见 [06-代码生成器](./06-代码生成器.md)。配置类能力见 [12-生成页配置](./12-生成页配置.md)。

## 注意事项

- 扩展文件缺失会导致生成页 `import` 失败；不要删除 `types.ts` 与对应表的扩展文件。
- `requireSelection: true` 仅用于工具栏；行内用 `visible` / `disabled` 按行控制。
- 自定义按钮务必设置 `permission`，否则任何登录用户都能看到该按钮。
- 修改 Builder / 模板后需**重新编译并重启 WebApi** 再生成。
