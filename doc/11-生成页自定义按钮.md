# 生成页自定义按钮开发指南

生成的 CRUD 页面支持**行多选**、**工具栏自定义按钮**与**行内自定义按钮**。业务逻辑写在扩展文件中，**重新生成 Vue 不会覆盖扩展文件**。

## 相关能力

| 能力 | 说明 |
|------|------|
| 行多选 | 表格左侧复选框，维护 `selectedRows` / `selectedIds` |
| 批量删除 | 工具栏默认按钮（带删除图标），调用 `/api/{表名}/del` |
| 新增 | 工具栏默认按钮（带加号图标） |
| 导入 / 导出 | 默认按钮；`Import` / `Export` 权限；Excel（`.xlsx`） |
| 列设置 | 工具栏图标按钮；拖拽排序 + 显隐；偏好存 `localStorage` |
| 工具栏自定义按钮 | `toolbarButtons`：批量操作、跳转等 |
| 行内自定义按钮 | `rowButtons`：操作列，位于「编辑」与「删除」之间 |
| 查询区 | `searchFields`：配置可查询字段 |
| 主子表 | `detailTables`：`below` 下方明细 / `dialog` 行内弹窗 |
| CRUD 钩子 | `hooks`：拦截默认新增、修改、删除 |

## 文件约定

| 路径 | 是否可覆盖 | 说明 |
|------|------------|------|
| `src/views/{文件夹}/{表名}.vue` | 是（生成会覆盖） | 列表 / 表单骨架 |
| `src/extension/{文件夹}/{表名}.ts` | **否** | 自定义按钮与业务扩展 |
| `src/extension/types.ts` | 手写维护 | `PageExtension` / 按钮 / 主子表 / 查询 / hooks |
| `src/constants/actionIcons.ts` | 手写维护 | 统一操作图标 `ActionIcons` |
| `src/components/TableColumnSettings.vue` | 手写维护 | 列显隐 / 排序弹窗 |
| `src/composables/useTableColumns.ts` | 手写维护 | 列偏好（localStorage） |

示例（设备页）：

- 页面：`Seven.Vue3/src/views/Board/Device.vue`
- 扩展：`Seven.Vue3/src/extension/Board/Device.ts`

首次「生成 Vue」时，若扩展文件不存在会自动创建空模板；再次生成只覆盖 `.vue`。

## 默认按钮图标

生成页工具栏 / 行操作默认使用 `ActionIcons`：

| 按钮 | 图标 |
|------|------|
| 新增 | `ActionIcons.add` |
| 批量删除 | `ActionIcons.batchDelete` |
| 导入 | `ActionIcons.import` |
| 导出 | `ActionIcons.export` |
| 列设置 | `ActionIcons.columnSettings` |
| 行内编辑 | `ActionIcons.edit` |
| 行内删除 | `ActionIcons.delete` |
| 弹窗确定 | `ActionIcons.save` |

## 列设置（自定义排序）

- 入口：工具栏右侧齿轮图标，无权限限制（仅影响本机显示）。
- 偏好键：`crud-columns:{表名}`，存浏览器 `localStorage`（顺序 + 是否显示）。
- 刷新页面后仍生效；换浏览器 / 清缓存会恢复默认。
- 列表列由生成时的 `allColumns`（ColumnDefs）驱动，按偏好过滤排序后 `v-for` 渲染。

## 导入 / 导出

后端接口（重新生成 **服务端** 后才有；仅刷 Vue 不够）：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/{表名}/export` | 按分页条件导出，最多 10000 行，返回 `.xlsx` |
| GET | `/api/{表名}/exportTemplate` | 下载导入模板（可编辑字段表头） |
| POST | `/api/{表名}/import` | `multipart` 字段名 `file`，批量新增 |

前端按钮权限：

- 导入 / 下载模板：`{表名}.Import`
- 导出：`{表名}.Export`

请在菜单管理中为对应菜单的 `Auth` 增加 `Import,Export`，并给角色勾选后重新登录或刷新权限。种子数据里设备菜单已包含这两项（仅影响新库）。

Excel 表头使用**实体属性名**（如 `DeviceName`），与导入模板一致。

## 扩展 API

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'

const extension: PageExtension = {
  toolbarButtons: [
    // 工具栏
  ],
  rowButtons: [
    // 行内操作列
  ],
}

export default extension
```

### ToolbarButton

| 字段 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 唯一键 |
| `label` | `string` | 按钮文案 |
| `icon` | `Component?` | 图标组件，推荐 `ActionIcons.xxx` |
| `permission` | `string?` | 权限码，如 `Device.Update` |
| `type` | Element Plus 按钮 type | 可选 |
| `requireSelection` | `boolean?` | `true` 时未勾选行则禁用 |
| `onClick` | `(ctx: PageActionContext) => void \| Promise<void>` | 点击处理 |

### RowButton（行内）

| 字段 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 唯一键 |
| `label` | `string` | 按钮文案 |
| `icon` | `Component?` | 图标组件 |
| `permission` | `string?` | 权限码，如 `Device.Search` |
| `type` | link 按钮颜色 | 默认 `primary` |
| `visible` | `(row) => boolean` | 按行控制是否显示 |
| `disabled` | `(row) => boolean` | 按行控制是否禁用 |
| `onClick` | `(ctx: RowActionContext) => void \| Promise<void>` | 点击处理 |

显示位置：操作列中 **编辑之后、删除之前**。操作列宽度会随按钮数量自动加宽。

### PageActionContext / RowActionContext

| 字段 | 说明 |
|------|------|
| `selectedRows` | 勾选行（行内点击时为 `[当前行]`） |
| `selectedIds` | 主键 Id 数组（行内为 `[rowId]`） |
| `row` / `rowId` | **仅 RowActionContext**：当前行对象与主键 |
| `reload` | 重新加载列表 |
| `http` | Axios 封装 |
| `router` | Vue Router |
| `t` | i18n `t` |

### searchFields（查询区）

配置后列表上方出现查询表单；未配置则不显示。

| 字段 | 说明 |
|------|------|
| `prop` | 字段名（camelCase，与实体属性对应） |
| `label` / `labelKey` | 文案；不传则用 `generated.{表}.{prop}` |
| `kind` | `string` / `number` / `enum` / `date` / `bool` |
| `operator` | `like` / `equal`；默认 string→like，其它→equal |
| `options` | 枚举/下拉选项 |

查询参数写入 `PageDataOptions.Wheres`（JSON 数组），由后端 `CrudHelper.ApplyWheres` 统一过滤。**需重启 WebApi** 使过滤生效。

```ts
searchFields: [
  { prop: 'deviceName', kind: 'string' },
  { prop: 'status', kind: 'enum', options: [{ value: 1, label: '在线' }] },
],
```

### detailTables（主子表一对多）

| 字段 | 说明 |
|------|------|
| `key` | 唯一键 |
| `title` | 标题；dialog 模式下默认作为行内按钮文案 |
| `mode` | `below`：选中主表行后在下方展示；`dialog`：行内按钮弹窗 |
| `buttonLabel` | 仅 dialog：自定义行内按钮文案 |
| `apiRoute` + `foreignKey` | 调子表 `getPageData`，按外键 equal 过滤 |
| `masterKey` | 主表主键字段，默认页面主键 |
| `load` | 自定义加载函数（优先于 apiRoute），适合 Demo/聚合 |
| `columns` | 子表列定义 |
| `permission` | 可选权限码 |

```ts
detailTables: [
  {
    key: 'lines',
    title: '订单明细',
    mode: 'below',           // a. 下方显示
    apiRoute: 'OrderLine',
    foreignKey: 'orderId',
    masterKey: 'orderId',
    columns: [
      { prop: 'materialCode', label: '物料编码' },
      { prop: 'qty', label: '数量', kind: 'number' },
    ],
  },
  {
    key: 'parts',
    title: '备件清单',
    mode: 'dialog',          // b. 行内按钮弹窗
    buttonLabel: '备件清单',
    load: async (master) => [/* ... */],
    columns: [{ prop: 'name', label: '名称' }],
  },
],
```

`below`：点击行或勾选行后加载明细；`dialog`：操作列自动出现以 `title`/`buttonLabel` 命名的按钮。

### hooks（拦截默认增删改）

返回 `false` 则中断后续默认逻辑。

| 钩子 | 时机 |
|------|------|
| `beforeOpenForm` | 打开新增/编辑弹窗前 |
| `beforeSave` | 点确定提交前（可改 `form`） |
| `afterSave` | 保存成功后 |
| `beforeDelete` | 确认框之前（单行/批量） |
| `afterDelete` | 删除成功后 |

```ts
hooks: {
  async beforeSave({ mode, form }) {
    if (!String(form.deviceName ?? '').trim()) {
      ElMessage.warning('名称必填')
      return false
    }
    return true
  },
  async beforeDelete({ ids }) {
    if (ids.length > 10) return false
    return true
  },
},
```

### 常用 ActionIcons

| 键 | 用途 |
|----|------|
| `add` / `addChild` / `addSibling` | 新增 |
| `edit` | 编辑 |
| `delete` / `batchDelete` | 删除 |
| `sync` | 同步 / 自定义处理 |
| `save` / `confirm` / `cancel` | 保存 / 确定 / 取消 |
| `viewAll` | 跳转 / 查看 |
| `config` | 配置 |

## 示例 1：提交后台处理（带图标）

在 `src/extension/Board/Device.ts`：

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'
import { ElMessage } from 'element-plus'

const extension: PageExtension = {
  toolbarButtons: [
    {
      key: 'customAction',
      label: '自定义处理',
      icon: ActionIcons.sync,
      permission: 'Device.Custom',
      type: 'warning',
      requireSelection: true,
      async onClick(ctx) {
        const res = await ctx.http.post<{ status: boolean; message?: string }>(
          '/api/Device/custom',
          ctx.selectedIds,
        )
        if (res.status) {
          ElMessage.success(ctx.t('common.success'))
          await ctx.reload()
        } else {
          ElMessage.error(res.message || ctx.t('common.operationFailed'))
        }
      },
    },
  ],
}

export default extension
```

后端需自行提供对应接口（如 `POST /api/Device/custom`，body 为 `int[]`）。

菜单侧需注册动作码 `Custom`（见上文「自定义按钮如何挂到菜单权限」），再给角色勾选 `Device.Custom`。

## 示例 2：打开自定义页并传入选中数据

Demo 权限（须在菜单 Auth 勾选后，再给角色授权才会显示）：

| 按钮 | 权限码 | 菜单动作 |
|------|--------|----------|
| 工具栏「批量处理」 | `Device.BatchCustom` | `BatchCustom` |
| 行内「处理」 | `Device.RowCustom` | `RowCustom` |

1. **菜单管理** → 设备管理 → 勾选 `BatchCustom`、`RowCustom` → 保存  
2. **角色管理** → 权限 → 勾选「批量处理」「行内处理」→ 保存权限  
3. 刷新页面（当前角色会自动刷新权限）

Demo 打开方式为**弹窗**（非新路由）：

| 文件 | 作用 |
|------|------|
| [`extension/Board/Device.ts`](../Seven.Vue3/src/extension/Board/Device.ts) | 按钮 + `overlay: DeviceCustomDialog` |
| [`components/DeviceCustomDialog.vue`](../Seven.Vue3/src/components/DeviceCustomDialog.vue) | 弹窗：展示 / 编辑 / 提交 |
| [`extension/Board/deviceCustomShared.ts`](../Seven.Vue3/src/extension/Board/deviceCustomShared.ts) | 弹窗开关与数据 |

生成页通过 `<component :is="pageExtension.overlay" />` 挂载扩展弹窗；扩展里 `openDeviceCustomDialog({ mode, rows, reload })` 即可打开。

通用写法（其它表可照搬）：

```ts
import MyDialog from '../../components/MyDialog.vue'
import { openMyDialog } from './myDialogState'

const extension: PageExtension = {
  overlay: MyDialog,
  toolbarButtons: [{
    key: 'batch',
    label: '批量处理',
    permission: 'Device.BatchCustom',
    requireSelection: true,
    onClick(ctx) {
      openMyDialog({ rows: ctx.selectedRows, reload: ctx.reload })
    },
  }],
}
```

## 示例 3：行内自定义按钮

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'
import { ElMessage } from 'element-plus'

const extension: PageExtension = {
  toolbarButtons: [],
  rowButtons: [
    {
      key: 'rowDetail',
      label: '详情',
      icon: ActionIcons.viewAll,
      permission: 'Device.Search',
      async onClick(ctx) {
        ctx.router.push({
          path: '/DeviceDetail',
          query: { id: String(ctx.rowId) },
        })
      },
    },
    {
      key: 'rowRestart',
      label: '重启',
      icon: ActionIcons.sync,
      type: 'warning',
      permission: 'Device.Custom',
      // 仅离线设备显示
      visible: (row) => Number(row.status) === 0,
      async onClick(ctx) {
        const res = await ctx.http.post<{ status: boolean; message?: string }>(
          '/api/Device/restart',
          { id: ctx.rowId },
        )
        if (res.status) {
          ElMessage.success(ctx.t('common.success'))
          await ctx.reload()
        } else {
          ElMessage.error(res.message || ctx.t('common.operationFailed'))
        }
      },
    },
  ],
}

export default extension
```

行内权限同样走菜单 Auth 动作码（见下文）；`visible` / `disabled` 仅控制该行是否展示或可点。

## 开发步骤（推荐）

1. 用代码生成器生成 Vue 页（会顺带创建扩展文件）。
2. 打开 `src/extension/{文件夹}/{表名}.ts`，在 `toolbarButtons` / `rowButtons` 中增加按钮。
3. 按下方「自定义按钮如何挂到菜单权限」配置 `permission` 对应的动作码。
4. 若跳转新页面：新增 Vue 视图 + 菜单 Url / 动态路由。
5. **不要**把业务写进生成的 `.vue`，否则下次生成会被覆盖。

## 自定义按钮如何挂到菜单权限

扩展按钮的 `permission` 格式固定为 **`{表名}.{动作码}`**，例如：

```ts
{
  key: 'customAction',
  label: '自定义处理',
  icon: ActionIcons.sync,
  permission: 'Device.Custom',  // ← Device = 菜单「视图/表名」，Custom = 动作码
  ...
}
```

### 在菜单里注册动作码

1. 打开 **系统管理 → 菜单管理**，选中对应页面菜单（如「设备管理」）。
2. 确认 **视图/表名** 为 `Device`（与权限前缀一致）。
3. 在 **按钮权限** 区域：
   - 常用动作（Search / Add / Import …）直接勾选；
   - **自定义动作**：在输入框填写动作码（如 `Custom`，须以字母开头），点 **添加动作**，再勾选它。
4. 点 **保存**。此时 `Sys_Menu.Auth` 会变成类似：`Search,Add,Update,Delete,Custom`。

### 在角色授权里勾选

1. **角色管理 → 权限**，找到「设备管理」。
2. 会出现刚才注册的动作（无中文映射时显示英文码 `Custom`）。
3. 勾选后 **保存权限**。
4. 当前登录角色会自动刷新；其它账号需重新登录。

之后前端 `hasPermission('Device.Custom')` 为真，扩展按钮才会显示。

> 角色弹窗里的中文名来自后端 `ActionLabels`。若希望显示「自定义处理」而不是 `Custom`，可在 `SystemServices.ActionLabels` 中增加 `["Custom"] = "自定义处理"`（可选）。

### 与导入导出的区别

| 类型 | 动作码 | 菜单操作 |
|------|--------|----------|
| 导入 / 导出 | `Import` / `Export` | 勾选预设项即可 |
| 扩展自定义按钮 | 自定，如 `Custom` | 用「添加动作」写入后再勾选 |

## 注意事项

- 扩展文件缺失会导致生成页 `import` 失败；不要删除 `types.ts` 与对应表的扩展文件。
- `requireSelection: true` 仅用于工具栏；行内用 `visible` / `disabled` 按行控制。
- 自定义按钮务必设置 `permission`（如 `Device.Update`），否则任何登录用户都能看到该按钮。
- `icon` 可选；不传则只显示文字。
- 生成页默认按钮用 `userStore.hasPermission('Device.Add')` 控制显示；取消角色授权并保存后，当前角色会立即刷新权限。
- 批量删除走通用 `common.batchDelete` 文案；自定义按钮文案可写死或使用 `ctx.t('...')`。
- 修改 Builder / 模板后需**重新编译并重启 WebApi** 再生成。
