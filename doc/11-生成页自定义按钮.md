# 生成页自定义按钮开发指南

生成的 CRUD 页面支持**行多选**与**工具栏自定义按钮**。业务逻辑写在扩展文件中，**重新生成 Vue 不会覆盖扩展文件**。

## 相关能力

| 能力 | 说明 |
|------|------|
| 行多选 | 表格左侧复选框，维护 `selectedRows` / `selectedIds` |
| 批量删除 | 工具栏默认按钮（带删除图标），调用 `/api/{表名}/del` |
| 新增 | 工具栏默认按钮（带加号图标） |
| 导入 / 导出 | 默认按钮；`Import` / `Export` 权限；Excel（`.xlsx`） |
| 列设置 | 工具栏图标按钮；拖拽排序 + 显隐；偏好存 `localStorage` |
| 自定义按钮 | 在扩展文件中声明，可配置图标、调接口或跳转自定义页 |

## 文件约定

| 路径 | 是否可覆盖 | 说明 |
|------|------------|------|
| `src/views/{文件夹}/{表名}.vue` | 是（生成会覆盖） | 列表 / 表单骨架 |
| `src/extension/{文件夹}/{表名}.ts` | **否** | 自定义按钮与业务扩展 |
| `src/extension/types.ts` | 手写维护 | `PageExtension` / `ToolbarButton` 类型 |
| `src/constants/actionIcons.ts` | 手写维护 | 统一操作图标 `ActionIcons` |
| `src/components/TableColumnSettings.vue` | 手写维护 | 列显隐 / 排序弹窗 |
| `src/composables/useTableColumns.ts` | 手写维护 | 列偏好（localStorage） |

示例（设备页）：

- 页面：`Seven.Vue3/src/views/Board/Device.vue`
- 扩展：`Seven.Vue3/src/extension/Board/Device.ts`

首次「生成 Vue」时，若扩展文件不存在会自动创建空模板；再次生成只覆盖 `.vue`。

## 默认按钮图标

生成页工具栏 / 行操作默认使用 `ActionIcons`：

| 按钮 | 图标 |
|------|------|
| 新增 | `ActionIcons.add` |
| 批量删除 | `ActionIcons.batchDelete` |
| 导入 | `ActionIcons.import` |
| 导出 | `ActionIcons.export` |
| 列设置 | `ActionIcons.columnSettings` |
| 行内编辑 | `ActionIcons.edit` |
| 行内删除 | `ActionIcons.delete` |
| 弹窗确定 | `ActionIcons.save` |

## 列设置（自定义排序）

- 入口：工具栏右侧齿轮图标，无权限限制（仅影响本机显示）。
- 偏好键：`crud-columns:{表名}`，存浏览器 `localStorage`（顺序 + 是否显示）。
- 刷新页面后仍生效；换浏览器 / 清缓存会恢复默认。
- 列表列由生成时的 `allColumns`（ColumnDefs）驱动，按偏好过滤排序后 `v-for` 渲染。

## 导入 / 导出

后端接口（重新生成 **服务端** 后才有；仅刷 Vue 不够）：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/{表名}/export` | 按分页条件导出，最多 10000 行，返回 `.xlsx` |
| GET | `/api/{表名}/exportTemplate` | 下载导入模板（可编辑字段表头） |
| POST | `/api/{表名}/import` | `multipart` 字段名 `file`，批量新增 |

前端按钮权限：

- 导入 / 下载模板：`{表名}.Import`
- 导出：`{表名}.Export`

请在菜单管理中为对应菜单的 `Auth` 增加 `Import,Export`，并给角色勾选后重新登录或刷新权限。种子数据里设备菜单已包含这两项（仅影响新库）。

Excel 表头使用**实体属性名**（如 `DeviceName`），与导入模板一致。

## 扩展 API

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'

const extension: PageExtension = {
  toolbarButtons: [
    // 见下方示例
  ],
}

export default extension
```

### ToolbarButton

| 字段 | 类型 | 说明 |
|------|------|------|
| `key` | `string` | 唯一键 |
| `label` | `string` | 按钮文案 |
| `icon` | `Component?` | 图标组件，推荐 `ActionIcons.xxx` |
| `permission` | `string?` | 权限码，如 `Device.Update` |
| `type` | Element Plus 按钮 type | 可选 |
| `requireSelection` | `boolean?` | `true` 时未勾选行则禁用 |
| `onClick` | `(ctx) => void \| Promise<void>` | 点击处理 |

### PageActionContext（onClick 入参）

| 字段 | 说明 |
|------|------|
| `selectedRows` | 当前勾选的行对象数组 |
| `selectedIds` | 主键 Id 数组（number） |
| `reload` | 重新加载列表 |
| `http` | 与页面相同的 Axios 封装（`get` / `post`） |
| `router` | Vue Router，用于跳转 |
| `t` | i18n `t` 函数 |

### 常用 ActionIcons

| 键 | 用途 |
|----|------|
| `add` / `addChild` / `addSibling` | 新增 |
| `edit` | 编辑 |
| `delete` / `batchDelete` | 删除 |
| `sync` | 同步 / 自定义处理 |
| `save` / `confirm` / `cancel` | 保存 / 确定 / 取消 |
| `viewAll` | 跳转 / 查看 |
| `config` | 配置 |
| `acknowledge` / `clear` / `testRaise` | 告警相关 |

也可直接从 `@element-plus/icons-vue` 引入任意图标组件赋给 `icon`。

## 示例 1：提交后台处理（带图标）

在 `src/extension/Board/Device.ts`：

```ts
import type { PageExtension } from '../types'
import { ActionIcons } from '../../constants/actionIcons'
import { ElMessage } from 'element-plus'

const extension: PageExtension = {
  toolbarButtons: [
    {
      key: 'customAction',
      label: '自定义处理',
      icon: ActionIcons.sync,
      permission: 'Device.Custom',
      type: 'warning',
      requireSelection: true,
      async onClick(ctx) {
        const res = await ctx.http.post<{ status: boolean; message?: string }>(
          '/api/Device/custom',
          ctx.selectedIds,
        )
        if (res.status) {
          ElMessage.success(ctx.t('common.success'))
          await ctx.reload()
        } else {
          ElMessage.error(res.message || ctx.t('common.operationFailed'))
        }
      },
    },
  ],
}

export default extension
```

后端需自行提供对应接口（如 `POST /api/Device/custom`，body 为 `int[]`）。

菜单侧需注册动作码 `Custom`（见上文「自定义按钮如何挂到菜单权限」），再给角色勾选 `Device.Custom`。

## 示例 2：打开自定义页并传入选中数据

```ts
{
  key: 'openBatch',
  label: '批量页',
  icon: ActionIcons.viewAll,
  requireSelection: true,
  onClick(ctx) {
    ctx.router.push({
      path: '/DeviceBatch',
      query: { ids: ctx.selectedIds.join(',') },
    })
  },
}
```

目标页需自行在路由 / 菜单中注册；在页面内读取：

```ts
import { useRoute } from 'vue-router'

const route = useRoute()
const ids = String(route.query.ids || '')
  .split(',')
  .map(Number)
  .filter((n) => n > 0)
```

## 开发步骤（推荐）

1. 用代码生成器生成 Vue 页（会顺带创建扩展文件）。
2. 打开 `src/extension/{文件夹}/{表名}.ts`，在 `toolbarButtons` 中增加按钮，并用 `ActionIcons` 设置 `icon`。
3. 按下方「自定义按钮如何挂到菜单权限」配置 `permission` 对应的动作码。
4. 若跳转新页面：新增 Vue 视图 + 菜单 Url / 动态路由。
5. **不要**把业务写进生成的 `.vue`，否则下次生成会被覆盖。

## 自定义按钮如何挂到菜单权限

扩展按钮的 `permission` 格式固定为 **`{表名}.{动作码}`**，例如：

```ts
{
  key: 'customAction',
  label: '自定义处理',
  icon: ActionIcons.sync,
  permission: 'Device.Custom',  // ← Device = 菜单「视图/表名」，Custom = 动作码
  ...
}
```

### 在菜单里注册动作码

1. 打开 **系统管理 → 菜单管理**，选中对应页面菜单（如「设备管理」）。
2. 确认 **视图/表名** 为 `Device`（与权限前缀一致）。
3. 在 **按钮权限** 区域：
   - 常用动作（Search / Add / Import …）直接勾选；
   - **自定义动作**：在输入框填写动作码（如 `Custom`，须以字母开头），点 **添加动作**，再勾选它。
4. 点 **保存**。此时 `Sys_Menu.Auth` 会变成类似：`Search,Add,Update,Delete,Custom`。

### 在角色授权里勾选

1. **角色管理 → 权限**，找到「设备管理」。
2. 会出现刚才注册的动作（无中文映射时显示英文码 `Custom`）。
3. 勾选后 **保存权限**。
4. 当前登录角色会自动刷新；其它账号需重新登录。

之后前端 `hasPermission('Device.Custom')` 为真，扩展按钮才会显示。

> 角色弹窗里的中文名来自后端 `ActionLabels`。若希望显示「自定义处理」而不是 `Custom`，可在 `SystemServices.ActionLabels` 中增加 `["Custom"] = "自定义处理"`（可选）。

### 与导入导出的区别

| 类型 | 动作码 | 菜单操作 |
|------|--------|----------|
| 导入 / 导出 | `Import` / `Export` | 勾选预设项即可 |
| 扩展自定义按钮 | 自定，如 `Custom` | 用「添加动作」写入后再勾选 |

## 注意事项

- 扩展文件缺失会导致生成页 `import` 失败；不要删除 `types.ts` 与对应表的扩展文件。
- `requireSelection: true` 时未选中会禁用按钮；点击时仍建议做空选校验。
- 自定义按钮务必设置 `permission`（如 `Device.Update`），否则任何登录用户都能看到该按钮。
- `icon` 可选；不传则只显示文字。
- 生成页默认按钮用 `userStore.hasPermission('Device.Add')` 控制显示；取消角色授权并保存后，当前角色会立即刷新权限。
- 批量删除走通用 `common.batchDelete` 文案；自定义按钮文案可写死或使用 `ctx.t('...')`。
- 修改 Builder / 模板后需**重新编译并重启 WebApi** 再生成。
