# 21 — 仿真器与联调闭环（实施流程）

本文说明如何用 **Seven.Simulator** 完成：

**编辑地图 → 部署（生成主数据）→ 仿真测试（Gateway/Trigger 通讯）→ 切换生产（真机 IP、通讯包）**。

## 3. 实施流程（产品四步）

### 3.1 ① 编辑地图

1. 打开 Simulator → **Features**：勾选本项目组合（例：Wms + Bus + Stacker；四向另开 FourWay + 建议 HotStore）。
2. 导出 appsettings 片段，合并进 WebApi 配置（生产以环境配置为准；工程 meta 仅记录意图）。
3. **地图**：
   - 一期：导入/编辑 JSON 节点，或简易表单添加节点、边、申请点。
   - 四期：**`.simproj.json` 适配导入**（MapEditor）、**栅格 JSON 导入**（`{ packId, cells: [{ code, x, y }] }`）、**路径组预览**（连通分量启发式）。
   - 二期及以后：2D 画布拖设备、端口连线、拓扑校验通过后再 Deploy。
4. 保存工程为 `{名称}.sevenproj.json`（可版本管理）。

**原则：** 未 Deploy 的地图只存在于工程文件，不会进业务库。

### 3.2 ② 部署（生成主数据）

1. 地图页点击 **Deploy**。
2. 后端写入：
   - 仓：`SIM_{工程名}`（`Wms_Warehouse`）
   - 货位：`Wms_Location`（自动补 `Stk.` / `Fw.` 前缀）
   - 包种子：堆垛 `Stk_RequestPoint` / `Stk_Route` 等；四向 `FwMapVersion` / `FwNode` / `FwRoute`
   - 可选：`Scd_View` + `Scd_NodeBind`（供 Vue3 Floor2d）
   - 记录：`Sim_Deployment`
3. 用 Vue3 **仓库/库位/申请点** 菜单核对数据。
4. 需要推倒重来：**Undeploy**（可选删除空库位）后再改图 Deploy。

### 3.3 ③ 仿真测试（Gateway 通讯）

分两档（工程字段 `meta.simCommsMode`）：

| 档 | 模式 | 何时用 | 怎么测 |
|----|------|--------|--------|
| **A** | Trigger（语义 Gateway） | 一期默认；状态机/分配联调 | Player 发 SUDR / 段反馈；或 Vue3 堆垛/四向 Trigger 页 |
| **B** | Gateway 协议保真 | 三期；报文/动画 | Start Gateway → SignalR 代理 → TCP 监听 + Emulator |

推荐联调顺序：

1. Deploy 成功后，Player 保持 **Simulation**。
2. **档 A**：发送目的地申请 → 观察包任务 / `Bus_TransportOrder`（Vue3 运输单监控）。
3. 走一笔入库：Simulator 快捷入口或 Vue3 入库单（建单→审核→组盘）。
4. **Reset**：清运行态，保留 `SIM_` 主数据，便于反复测。
5. 档 B（具备后）：确认 `wcsConnections` 端口无冲突，再 Start Gateway。

### 3.4 ④ 切换生产（真机 IP、通讯包）

**禁止：** 在仿真身份下只把设备 IP 改成真机。

正确路径：

1. Promote 页填写各设备 **真实 Host:Port:协议**（禁止 `127.0.0.1` / `localhost`）。
2. 先 **promote-preview** 核对清单，再 **Promote**。
3. 启用 `Features.DeviceComm`（或项目通讯包），在 Vue3 配置 `CommConnection` / 点位 / 规则。
4. 将 `IEquipmentTriggerPort` 切换为真机实现（或由通讯包驱动）——见 [16-设备通讯DeviceComm](./16-设备通讯DeviceComm.md)。
5. 用 Vue3 做单据、联锁、急停验收；Simulator 可切回工程仅作地图变更源（变更仍须 Deploy/变更管理）。

## 4. 开发实施流程（一期→四期）

按计划 **顺序执行**，每期门禁通过后再进入下一期。

| 期 | 目标 | 门禁 |
|----|------|------|
| **I** | 闭环可演示：schema、Deploy 增强、Reset、Promote、Player Trigger | 堆垛 Demo：Deploy→Trigger→Promote preview 拒环回 |
| **II** | Vue 2D 完整编辑器（设备库、连线、拓扑） | 手动画简易立库并 Deploy |
| **III** | Three.js Player + TCP Gateway + SignalR | Gateway 收发报文且 3D 有反馈 |
| **IV** | `.simproj` 适配、JSON 栅格导入、路径组预览 | RCS Demo JSON 导入可 Deploy |

**Phase IV 完成门禁（已实现，MVP）：**

1. MapEditor 导入 `fixtures/minimal.simproj.json` → 不支持设备类型（如 Shuttle）进入 warnings，不阻断。
2. MapEditor 导入栅格 JSON（`fixtures/sample-grid.json` 格式）→ 合并 nodes 后可 Deploy。
3. MapEditor / Player 调用路径组预览 → 连通分量 + 环检测警告。

**Phase IV 范围说明：** Excel 原生上传未实现；四向栅格请 Excel 导出 CSV/JSON 后走 `import-grid` API。完整调度看板留后续迭代。

**Phase I 完成门禁（已实现）：** 堆垛 Demo 工程 **Deploy** 成功 → Player **Trigger** 返回成功 → **Promote preview** 对 `127.0.0.1` / `localhost` / `::1` 返回错误。Reset / Promote API 与 `SimulationController` 路由已落地，见 §5。

详细 Task 列表见计划文档。建议代理执行用 **subagent-driven-development**，每 Task 验收后再派下一个。

## 5. API 速查

路由来源：`Seven.WebApi/Controllers/Simulator/SimulationController.cs`（`[Route("api/simulation")]`，`[AllowAnonymous]`）。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/simulation/projects/validate-features` | Features 校验 |
| POST | `/api/simulation/deploy` | 生成主数据（body：`SimProjectDto`） |
| POST | `/api/simulation/undeploy` | 拆除部署 |
| GET | `/api/simulation/deployments` | 部署记录 |
| POST | `/api/simulation/reset` | 清运行态，保留 `SIM_` 主数据 |
| POST | `/api/simulation/promote-preview` | Promote 预览（拒环回地址） |
| POST | `/api/simulation/promote` | 写入 CommConnection + 标记 Promoted |
| POST | `/api/simulation/import-grid` | JSON 栅格 → `SimMapDto`（Phase IV） |
| POST | `/api/simulation/route-groups/preview` | 路径组启发式预览（Phase IV） |
| POST | `/api/Wcs/Triggers/destination-request` | 仿真档 A（需 JWT） |
| POST | `/api/Wcs/Triggers/segment-feedback` | 仿真档 A（需 JWT） |
| Hub | `/hubs/sim-wcs-proxy` | 仿真档 B（三期） |

### 5.1 请求体（Phase I）

| 路径 | Body |
|------|------|
| `undeploy` | `{ "projectName": "工程名", "removeLocations": false }` |
| `reset` | `{ "projectName": "工程名" }` |
| `promote-preview` / `promote` | `{ "projectName": "工程名", "devices": [{ "code", "host", "port", "protocol" }] }` |

`promote-preview` 与 `promote` 均拒绝环回 Host（`127.0.0.1` / `localhost` / `::1`，大小写不敏感）。

### 5.2 请求体（Phase IV）

| 路径 | Body |
|------|------|
| `import-grid` | `{ "packId": "fourway", "cells": [{ "code": "Fw.A-01", "x": 0, "y": 0 }] }` → `{ map: SimMapDto, warnings: [] }` |
| `route-groups/preview` | `{ "packId": "fourway", "nodes": [...], "edges": [...] }` → `{ suggested: [{ code, nodeIds[] }], warnings: [] }` |

栅格 JSON 样例见 `Seven.Simulator/fixtures/sample-grid.json`；simproj 样例见 `fixtures/minimal.simproj.json`。

## 7. 常见问题

**Q: Features.Simulator=false 还能 Deploy 吗？**  
能。该开关只影响前端入口/菜单；API 仍注册。

**Q: 仿真仓能否直接当生产仓改名？**  
不推荐。应 Promote 设备连接，业务仓按实施规范单独建或走变更流程；避免半仿真半真机。

**Q: 与 doc/20 的关系？**  
doc/20 描述 WMS/WCS **运行时实现**；本文描述 **如何用仿真器把主数据与通讯从设计态推到生产**。
