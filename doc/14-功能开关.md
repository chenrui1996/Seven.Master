# 功能开关（Features）

通过 `appsettings.json` 的 **`Features`** 节控制能力组合。约定：

| 类别 | 开关示例 | 关闭效果 |
|------|----------|----------|
| **模块 UI** | Wms、OrchestrationBus、WcsPacks、Simulator | **仅隐藏前端菜单/入口**；后端表、DI、业务 API **始终保留** |
| **基础设施** | Captcha、RateLimit、Tenant、MinIO、Mail、HotStore、DeviceComm、SignalR… | 仍控制中间件/宿主/连接等运行时行为（多数与细节节 AND） |

## 配置示例（默认偏简单 UI）

```json
"Features": {
  "WorkFlow": false,
  "Quartz": false,
  "SignalR": true,
  "Alarm": true,
  "MessageQueue": false,
  "Outbox": false,
  "Mail": false,
  "MinIO": false,
  "Tenant": false,
  "Captcha": false,
  "RateLimit": true,
  "Idempotency": true,
  "DataScope": true,
  "AuditInterceptor": true,
  "Builder": true,
  "HotStore": false,
  "DeviceComm": false,
  "Simulator": false,
  "Wms": false,
  "OrchestrationBus": false,
  "WcsPacks": {
    "Stacker": false,
    "FourWay": false,
    "BoxSort": false
  }
},
"ExternalWcs": []
```

> **Development 环境**：`appsettings.Development.json` **不再覆盖** Features，以 `appsettings.json` 为准。改完需**重启 WebApi**，并在前端**重新登录**才会隐藏菜单。

## 开关说明

| 开关 | 关闭效果 | 关联细节节 |
|------|----------|------------|
| WorkFlow | 工作流 API 404；前端隐藏流程/审批菜单 | — |
| Quartz | 不启动调度宿主；定时任务 API 404 | — |
| SignalR | 不 MapHub；通知 API 不可用；前端不连 Hub | — |
| Alarm | 告警 API 404；隐藏告警菜单/铃铛 | 通常配合 SignalR |
| MessageQueue | 强制 NoOp，不连 RabbitMQ | `MessageQueue:Provider` |
| Outbox | 不启动 OutboxProcessor | 需 MessageQueue=true |
| Mail | 发信返回未启用 | `Mail:Enabled`（AND） |
| MinIO | 使用本地 `Upload/` | `MinIO:Enabled`（AND） |
| Tenant | 不启用租户过滤器 | `Tenant:Enabled`（AND） |
| Captcha | 登录不校验；前端不显示验证码 | `Security:CaptchaEnabled`（AND） |
| RateLimit | 限额设为极大（等同关闭） | `Security:LoginPermitLimit` |
| Idempotency | 不挂防重中间件 | `Security:IdempotencySeconds` |
| DataScope | 查询视为「全部」数据范围 | 角色 `DataScope` |
| AuditInterceptor | 不挂字段审计拦截器（开启后变更写入 `Sys_Log`，页面：**系统管理 → 日志管理**） | 见 [01 §6](./01-快速开始.md#6-如何查看日志) |
| Builder | 代码生成 API 404；隐藏代码生成菜单 | — |
| HotStore | 不注册热数据宿主；`IHotStore` 为禁用占位 | `HotStore` 节；见 [15](./15-热数据HotStore.md) |
| DeviceComm | 不启动通讯宿主；通讯 API 404；隐藏通讯菜单 | `DeviceComm` 节；见 [16](./16-设备通讯DeviceComm.md) |
| **Wms** | **仅隐藏** WMS/SCADA 菜单；`Wms_*` 表与 API 仍可用 | 见 [19](./19-WMS与WCS包.md) |
| **OrchestrationBus** | **仅隐藏** 总线/运维相关菜单；`Bus_*` 与编排仍注册 | — |
| **WcsPacks.*** | **仅隐藏** 对应包菜单；包服务与表仍保留 | 嵌套布尔 |
| **Simulator** | **仅控制** 模拟器前端入口；Deploy API 始终可用 | 见 [design](../design/2026-08-29-seven-simulator-design.md) |
| ExternalWcs | 外部供应商包列表（非 Features 布尔） | `ExternalWcs` 数组节 |

**AND 约定**：基础设施开关 `Features.X && 细节节` 同时为真才真正启用（MinIO / Mail / Tenant / Captcha / HotStore / DeviceComm）。

## 前端

- 启动时请求 `GET /api/config/features`（匿名）→ `useFeatureStore`
- 动态菜单按 TableName / Url 过滤；无 url 的目录仅在仍有可见子菜单时保留
- 装载动态路由前会重新拉取 Features
- 登录验证码、AlarmBell、Home 广播区按基础设施类开关显示

## 推荐组合（UI 可见性）

| 场景 | 建议勾选（前端） |
|------|------------------|
| 极简后台 CRUD | 复杂模块 false |
| 纯 WMS 账本界面 | `Wms=true` |
| 巷道立库联调界面 | Wms + OrchestrationBus + WcsPacks.Stacker |
| 四向车库界面 | + HotStore（运行时）+ WcsPacks.FourWay |
| 工程联调模拟器 | + Simulator |

后端业务能力不因上述 UI 开关关闭而卸载。

## 环境变量

Docker/K8s 可用：`Features__WorkFlow=true`、`Features__DeviceComm=true` 等（见 [07-部署指南](./07-部署指南.md)）。
