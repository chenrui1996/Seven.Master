# 功能开关（Features）

简单项目无需启用全部企业能力。通过 `appsettings.json` 的 **`Features`** 节统一开关：后端不注册对应宿主/中间件/Hub，前端隐藏菜单与入口。

## 配置示例（默认偏简单）

```json
"Features": {
  "WorkFlow": false,
  "Quartz": false,
  "SignalR": true,
  "Alarm": true,
  "MessageQueue": false,
  "Outbox": false,
  "Mail": false,
  "MinIO": false,
  "Tenant": false,
  "Captcha": false,
  "RateLimit": true,
  "Idempotency": true,
  "DataScope": true,
  "AuditInterceptor": true,
  "Builder": true,
  "HotStore": false,
  "DeviceComm": false,
  "Simulator": false,
  "Wms": false,
  "OrchestrationBus": false,
  "WcsPacks": {
    "Stacker": false,
    "FourWay": false,
    "BoxSort": false
  }
},
"ExternalWcs": []
```

## 开关说明

| 开关 | 关闭效果 | 关联细节节 |
|------|----------|------------|
| WorkFlow | 工作流 API 404；前端隐藏流程/审批菜单 | — |
| Quartz | 不启动调度宿主；定时任务 API 404 | — |
| SignalR | 不 MapHub；通知 API 不可用；前端不连 Hub | — |
| Alarm | 告警 API 404；隐藏告警菜单/铃铛 | 通常配合 SignalR |
| MessageQueue | 强制 NoOp，不连 RabbitMQ | `MessageQueue:Provider` |
| Outbox | 不启动 OutboxProcessor | 需 MessageQueue=true |
| Mail | 发信返回未启用 | `Mail:Enabled`（AND） |
| MinIO | 使用本地 `Upload/` | `MinIO:Enabled`（AND） |
| Tenant | 不启用租户过滤器 | `Tenant:Enabled`（AND） |
| Captcha | 登录不校验；前端不显示验证码 | `Security:CaptchaEnabled`（AND） |
| RateLimit | 限额设为极大（等同关闭） | `Security:LoginPermitLimit` |
| Idempotency | 不挂防重中间件 | `Security:IdempotencySeconds` |
| DataScope | 查询视为「全部」数据范围 | 角色 `DataScope` |
| AuditInterceptor | 不挂字段审计拦截器（开启后变更写入 `Sys_Log`，页面：**系统管理 → 日志管理**） | 见 [01 §6](./01-快速开始.md#6-如何查看日志) |
| Builder | 代码生成 API 404；隐藏代码生成菜单 | — |
| HotStore | 不注册热数据宿主；`IHotStore` 为禁用占位；`/api/HotStore/*` 报未启用 | `HotStore` 节；思路与用法见 [15-热数据HotStore](./15-热数据HotStore.md) |
| DeviceComm | 不启动通讯宿主；网关/规则为占位；通讯 API 404；隐藏通讯菜单 | `DeviceComm` 节；见 [16-设备通讯DeviceComm](./16-设备通讯DeviceComm.md) |
| Wms | WMS/SCADA API 404；隐藏 WMS 菜单；库存与三单不可用 | 见 [19-WMS与WCS包](./19-WMS与WCS包.md) |
| OrchestrationBus | 不注册编排总线；`Bus_*` 运输单不可创建 | 需 Wms=true 才有意义 |
| WcsPacks.Stacker | 堆垛机包 HostedService 不启动；`Stk_*` 不可用 | 嵌套布尔；用 `IsWcsPackEnabled("Stacker")` |
| WcsPacks.FourWay | 四向车包不启动；`Fw_*` 不可用 | 通常配合 HotStore |
| WcsPacks.BoxSort | 箱式分拣包（预留） | — |
| Simulator | 仿真 Deploy/Undeploy API 404；`Seven.Simulator` 无法写库 | 见 [design 模拟器](../design/2026-08-29-seven-simulator-design.md) |
| ExternalWcs | 外部供应商包列表（非 Features 布尔） | `ExternalWcs` 数组节 |

**AND 约定**：`Features.X && 细节节` 同时为真才真正启用（MinIO / Mail / Tenant / Captcha / HotStore / DeviceComm）。

## 前端

- 启动时请求 `GET /api/config/features`（匿名）→ `useFeatureStore`
- 动态菜单按 TableName 过滤（`Sys_WorkFlow*`、`Sys_QuartzOptions`、`Sys_Alarm`、`Sys_TableInfo`、`DeviceCommFolder`/`CommConnection`/`CommPoint`/`CommRule`/`DeviceComm`）
- 登录验证码、AlarmBell、Home 广播区按开关显示

## 推荐组合

| 场景 | 建议 |
|------|------|
| 极简后台 CRUD | 全部复杂项 false；保留 RateLimit/DataScope/Builder |
| 标准业务系统 | + SignalR/Alarm；按需 WorkFlow/Quartz |
| 完整生产 | 全部 true，并配置 Redis/RabbitMQ/MinIO/Mail |
| WCS/调度热路径 | `HotStore=true` + `HotStore:Provider`（单活 Memory / 多活 Redis）；见 [15](./15-热数据HotStore.md) |
| PLC 设备通讯 | `DeviceComm=true` + `SignalR`（状态推送）+ 按需 `Alarm`；见 [16](./16-设备通讯DeviceComm.md) |
| 纯 WMS 账本联调 | `Wms=true`；总线与包可先 false |
| 巷道立库仿真 | Wms + OrchestrationBus + WcsPacks.Stacker；DeviceComm 可 false（InMemory 触发） |
| 四向车库 | + HotStore + WcsPacks.FourWay；生产 `HotStore:EnableDemoScheduler=false` |
| 工程联调（模拟器） | + Simulator；用 `Seven.Simulator`：Features→地图→仿真→Promote；见 [design](../design/2026-08-29-seven-simulator-design.md) |
| 外部 WCS 供应商 | + ExternalWcs 项；MessageQueue 按 Http/Mq 传输需要；见 [19](./19-WMS与WCS包.md) |

## 环境变量

Docker/K8s 可用：`Features__WorkFlow=true`、`Features__DeviceComm=true`、`DeviceComm__RuleScanIntervalMs=200` 等（见 [07-部署指南](./07-部署指南.md)）。
