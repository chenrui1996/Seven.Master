# 前端开发指南

## 技术栈

- Vue 3 + Composition API + TypeScript
- Vite
- Pinia（含 persistedstate）
- Vue Router 4（动态路由）
- Element Plus
- Axios（Token 自动刷新、业务失败 Toast）
- vue-i18n
- SignalR（告警 / 系统通知，受 Features 控制）

## 目录结构

```
Seven.Vue3/
├── src/
│   ├── api/            # Axios 封装、登录/菜单/字典/上传等
│   ├── assets/         # 图标、背景图案
│   ├── components/     # 公共组件（CrudPanel、AlarmBell、主题/语言切换）
│   ├── composables/    # useAlarmHub、useMessageHub、表格列等
│   ├── constants/      # 操作图标映射
│   ├── directives/     # v-permission
│   ├── extension/      # 生成页扩展（hooks/按钮，不被生成覆盖）
│   ├── layout/         # MainLayout（侧栏、标签、KeepAlive）
│   ├── locales/        # i18n 语言包与 Element Plus 本地化
│   ├── router/         # 路由、动态注册、权限守卫
│   ├── stores/         # user / menu / tabs / dict / theme / locale / features / alarm
│   ├── styles/         # 主题与按钮样式
│   ├── utils/          # 菜单树、主题、namedRouteComponent
│   ├── views/          # 页面（system/*、Business/*、Login、Home）
│   ├── App.vue
│   └── main.ts         # 启动时拉取 Features
├── docker/             # 前端镜像用 nginx 配置
├── Dockerfile
├── vite.config.ts
└── package.json
```

| 路径 | 说明 |
|------|------|
| `views/system/` | 系统管理页（用户/角色/菜单/字典/日志/工作流/Quartz…） |
| `views/system/Sys_Log.vue` | **日志管理**页；菜单「系统管理 → 日志管理」，路由 `/Sys_Log` |
| `views/Business/` | 业务生成页入口（如 Device） |
| `components/crud/` | 通用 CRUD 面板与扩展合并 |
| `extension/Business/` | 业务页自定义按钮与 hooks（含 `submitAudit`） |
| `stores/features.ts` | 功能开关；过滤菜单、控制验证码/Hub |

运行时文件日志（Serilog）不在前端查看，见 [01 §6](./01-快速开始.md#6-如何查看日志) / [02 §日志](./02-后端开发指南.md#日志)。

## 功能开关（前端）

启动调用 `GET /api/config/features`，见 [14-功能开关](./14-功能开关.md)。

- 关闭的功能对应菜单不会注册动态路由
- `Features.Captcha` 控制登录页验证码
- SignalR / Alarm 控制 Hub 连接与铃铛、Home 广播区
- `flags.hotStore` 对应后端 `Features.HotStore`；热通道用法见 [15-热数据HotStore](./15-热数据HotStore.md)

## 环境变量

`.env.development`：

```
VITE_API_BASE_URL=http://localhost:5000
```

## Axios

- 请求附加 `Authorization: Bearer {token}`
- 401：Refresh Token 队列；失败跳转登录
- 业务 `status:false`：统一 Toast（登录等白名单除外）

## 动态路由

1. 拉取 Features → 拉取 `/api/Sys_Menu/getMenu`
2. `featureStore.filterMenus` 后建树
3. `router.addRoute`；组件名与 KeepAlive `include` 联动

## 按钮权限

```vue
<el-button v-permission="'Sys_User.Add'">新增</el-button>
```

权限码格式：`{TableName}.{Action}`，与后端 `[Permission]` / 菜单 Auth 一致。
