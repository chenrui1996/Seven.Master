# 前端开发指南

## 技术栈

- Vue 3 + Composition API + TypeScript
- Vite 5
- Pinia（状态管理）
- Vue Router 4（动态路由）
- Element Plus
- Axios（Token 自动刷新）
- vue-i18n（国际化）

## 目录结构

```
Seven.Vue3/
├── src/
│   ├── api/           # API 请求封装
│   ├── assets/        # 静态资源
│   ├── components/    # 公共组件
│   ├── directives/    # v-permission 等指令
│   ├── layout/        # 布局（侧边栏、顶栏、标签页）
│   ├── router/        # 路由 + 守卫
│   ├── composables/   # useMenuLabel 等
│   ├── locales/       # vue-i18n 语言包（lang/*.json）
│   ├── extension/     # 生成页业务扩展（自定义按钮，不被生成覆盖）
│   ├── stores/        # Pinia（user/token/menu/dictionary/locale/theme）
│   ├── utils/         # 工具函数
│   ├── views/         # 页面
│   ├── App.vue
│   └── main.ts
├── vite.config.ts
└── package.json
```

生成页自定义按钮见 [11-生成页自定义按钮](./11-生成页自定义按钮.md)；列设置、查询、主子表等见 [12-生成页配置](./12-生成页配置.md)。

## 环境变量

`.env.development`:

```
VITE_API_BASE_URL=http://localhost:5000
```

## Axios 拦截器

- 请求：自动附加 `Authorization: Bearer {token}`
- 响应 401：尝试 Refresh Token，失败则跳转登录

## 动态路由

1. 登录成功后调用 `/api/Sys_Menu/getMenu` 获取菜单
2. 将菜单转换为 Vue Router 路由配置
3. `router.addRoute()` 动态注册

## 按钮权限

使用 `v-permission` 指令：

```vue
<el-button v-permission="'Sys_User.Add'">新增</el-button>
```

权限列表来自登录接口返回的 `permissions` 数组。

## 国际化（i18n）

- 库：**vue-i18n v11**（Composition API，`legacy: false`）
- 语言包：`src/locales/lang/*.json`，源语言为 `zh-CN.json`
- 切换：`LocaleSwitch` 组件 + `useLocaleStore()`
- Element Plus：`App.vue` 中 `el-config-provider` 绑定语言包

详细说明见 **[08-国际化指南](./08-国际化指南.md)**（配置翻译、新增语言、自动翻译脚本）。

```bash
npm run i18n:missing      # 检查 en-US 缺失键
npm run i18n:translate    # 自动翻译 en-US（需 API Key）
npm run i18n:translate:ja # 自动翻译 ja-JP
```

## 告警模块

后端通过 `IAlarmService.RaiseAsync` 抛出告警，经 SignalR 推送到前端顶栏铃铛与告警列表页。

详细说明见 **[09-告警模块](./09-告警模块.md)**（配置报警码、报警信息、API、权限）。
