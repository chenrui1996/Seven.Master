# 前端开发指南

## 技术栈

- Vue 3 + Composition API + TypeScript
- Vite 5
- Pinia（状态管理）
- Vue Router 4（动态路由）
- Element Plus
- Axios（Token 自动刷新）
- vue-i18n（国际化）

## 目录结构

```
Seven.Vue3/
├── src/
│   ├── api/           # API 请求封装
│   ├── assets/        # 静态资源
│   ├── components/    # 公共组件
│   ├── directives/    # v-permission 等指令
│   ├── layout/        # 布局（侧边栏、顶栏、标签页）
│   ├── router/        # 路由 + 守卫
│   ├── stores/        # Pinia（user/token/menu/dictionary）
│   ├── utils/         # 工具函数
│   ├── views/         # 页面
│   ├── App.vue
│   └── main.ts
├── vite.config.ts
└── package.json
```

## 环境变量

`.env.development`:

```
VITE_API_BASE_URL=http://localhost:5000
```

## Axios 拦截器

- 请求：自动附加 `Authorization: Bearer {token}`
- 响应 401：尝试 Refresh Token，失败则跳转登录

## 动态路由

1. 登录成功后调用 `/api/Sys_Menu/getMenu` 获取菜单
2. 将菜单转换为 Vue Router 路由配置
3. `router.addRoute()` 动态注册

## 按钮权限

使用 `v-permission` 指令：

```vue
<el-button v-permission="'Sys_User.Add'">新增</el-button>
```

权限列表来自登录接口返回的 `permissions` 数组。
