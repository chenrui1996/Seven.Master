# 生成页配置开发指南

生成页除自定义按钮外，还支持列设置、导入导出、查询区、CRUD 钩子与**主子表**。自定义按钮见 [11-生成页自定义按钮](./11-生成页自定义按钮.md)。

## 能力一览

| 能力 | 配置位置 | 说明 |
|------|----------|------|
| 列设置 | 生成页工具栏 | 拖拽排序 + 显隐；偏好存 `localStorage` |
| 导入 / 导出 | 生成页 + 后端接口 | Excel；需 `Import` / `Export` 权限 |
| 查询区 | 生成器列配置 / 扩展 `searchFields` | 写入 `PageDataOptions.Wheres` |
| CRUD 钩子 | 扩展 `hooks` | 拦截默认新增、修改、删除 |
| 主子表 | 生成器「子表」+ 扩展 `detailTables` | Below / Dialog / Page；最多 3 级 |

## 列设置

- 入口：工具栏右侧齿轮图标，无权限限制（仅影响本机显示）。
- 偏好键：`crud-columns:{表名}`，存浏览器 `localStorage`。
- 列表列由生成时的 `allColumns`（ColumnDefs）驱动，按偏好过滤排序后渲染。
- 组件：`TableColumnSettings.vue`、`useTableColumns.ts`。

## 导入 / 导出

后端接口（重新生成 **服务端** 后才有）：

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/{表名}/export` | 按分页条件导出，最多 10000 行 |
| GET | `/api/{表名}/exportTemplate` | 下载导入模板 |
| POST | `/api/{表名}/import` | `multipart` 字段名 `file` |

前端权限：`{表名}.Import` / `{表名}.Export`。菜单 Auth 需包含 `Import,Export`。

## searchFields（查询区）

可由扩展手写，或由代码生成器根据列的 `SearchRowNo` / `SearchType` 写入生成页。

| 字段 | 说明 |
|------|------|
| `prop` | 字段名（camelCase） |
| `label` / `labelKey` | 文案 |
| `kind` | `string` / `number` / `enum` / `date` / `bool` |
| `operator` | `like` / `equal` |
| `options` | 枚举选项 |

查询参数写入 `PageDataOptions.Wheres`，由 `CrudHelper.ApplyWheres` 过滤。

## hooks（拦截默认增删改）

返回 `false` 则中断后续默认逻辑。

| 钩子 | 时机 |
|------|------|
| `beforeOpenForm` | 打开新增/编辑弹窗前 |
| `beforeSave` | 点确定提交前（可改 `form`） |
| `afterSave` | 保存成功后 |
| `beforeDelete` | 确认框之前 |
| `afterDelete` | 删除成功后 |

## 主子表（一对多）

### 概念

- 主表 → 子表 → 孙表，**最多 3 级**；更深不再嵌套生成 UI。
- 显示方式：`Below`（主表下方）、`Dialog`（独立「子表」列弹窗）、`Page`（新标签打开子表标准页 + query 外键过滤）。
- Below / Dialog 内嵌完整 CRUD 面板（查询 + 增删改查 + 再嵌一层子表）；Page 复用已生成的标准页。

### 生成器配置（推荐）

1. 在 **代码生成** 页选中主表，打开 **子表** 页签。
2. 点 **扫描外键**：根据数据库外键候选写入 `Sys_TableDetail`（已有配置的启用状态/显示方式不覆盖）。
3. 勾选 **启用**，选择 **显示方式**，可改标题 / 外键 / 排序。
4. 保存后 **生成 Vue**：主表页面注入嵌套 `detailTables`（含子表 `searchFields`、列定义）。
5. **Page** 模式：请先为子表生成标准 Vue 页；跳转 URL 形如 `/{ChildTable}?{foreignKey}={masterId}`。

数据表：`Sys_TableDetail`（`ParentTable` / `ChildTable` / `ForeignKey` / `MasterKey` / `Enable` / `DisplayMode` / `OrderNo` / `CnName`）。

### 扩展覆盖

扩展 `detailTables` 与生成配置 **按 key merge**：同 key 以扩展为准，可追加或覆盖。

```ts
detailTables: [
  {
    key: 'SpareParts',
    title: '备件清单',
    mode: 'dialog', // below | dialog | page
    apiRoute: 'SpareParts',
    foreignKey: 'deviceId',
    masterKey: 'deviceId',
    columns: [/* ... */],
    searchFields: [/* ... */],
    children: [/* 孙表，depth≤3 */],
  },
]
```

| 字段 | 说明 |
|------|------|
| `mode` | `below` / `dialog` / `page` |
| `apiRoute` + `foreignKey` | 子表 API 与外键字段 |
| `masterKey` | 主表主键字段，默认页面主键 |
| `fixedFilter` | 固定查询条件（Page 模式由 route.query 写入） |
| `children` | 嵌套子表配置 |
| `load` | 自定义加载（仅只读 Demo；完整 CRUD 请用 apiRoute） |

### 子表入口列

- 操作列只保留：编辑 / 自定义 `rowButtons` / 删除。
- **子表列**单独展示 `Dialog` / `Page` 入口按钮；`Below` 不进该列。

### Page 模式

子表标准页读取 `route.query` 中的外键，写入 `fixedFilter` 并合并进列表查询，实现主表行过滤。

### 组件

- `CrudPanel.vue`：可嵌套 CRUD 面板（列表 / 查询 / 表单 / 默认按钮 / 子表）。
- 生成页外壳挂载 `CrudPanel`，并传入生成的 `detailTables` 与扩展 merge 结果。

## 与代码生成器

- 模板：`VuePage.html` → 生成页调用 `CrudPanel`
- 元数据：`Sys_TableDetail` + 列 `SearchType` / `SearchRowNo`
- 生成逻辑：`BuilderService.CreateVuePageAsync` 递归 depth≤3

更多见 [06-代码生成器](./06-代码生成器.md)。自定义按钮见 [11-生成页自定义按钮](./11-生成页自定义按钮.md)。

## Device Demo 对齐说明

实体 [`SubDevice`](../Seven.Net8/Seven.Domain/Entities/Business/Device.cs) 作为 `Device` 的一对多子表（外键 `DeviceId`）。

| 入口 | 说明 |
|------|------|
| Below | 选中设备后下方内嵌 `CrudPanel`，走 `/api/SubDevice` |
| Dialog | 「子表」列「子设备」弹窗 CRUD |
| Page | 「子表」列「子设备页」→ 新标签 `/SubDevice?deviceId=` |

配置来源：

- 种子：`Sys_TableDetail`（Device→SubDevice / Below）+ 菜单 `/SubDevice`
- 扩展：[`Business/Device.ts`](../Seven.Vue3/src/extension/Business/Device.ts) 同时演示三种 `mode`
- 子页：[`views/Business/SubDevice.vue`](../Seven.Vue3/src/views/Business/SubDevice.vue) 读取 `query.deviceId` 写入 `fixedFilter`
