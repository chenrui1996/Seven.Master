# 代码生成器

## 概述

Seven.Builder 模块参考 Legrand.Builder，支持表结构配置、MySQL 结构同步及 Entity / Service / Controller / Vue 页面生成。前端页面位于 `/coder`（`Sys_TableInfo.vue`）。

## 核心表

- `Sys_TableInfo`：表配置（ParentId 树、命名空间、文件夹等）
- `Sys_TableColumn`：列配置（显示、编辑、查询类型等）

新增字段通过 Migration `ExtendBuilderTables` 应用。

## 使用流程

1. 打开 **系统管理 → 代码生成**
2. **新建**：填写表名、中文名、命名空间、文件夹
3. **同步表结构**：从 MySQL `information_schema` 增量同步列（无 MySQL 时回退 EF 模型元数据）
4. 编辑列中文名、可编辑等属性后 **保存**
5. **生成 Model / 业务类 / Vue 页面**（输出到 `Seven.Domain`、`Seven.Infrastructure/Services`、`Seven.WebApi/Controllers/Generated`、`Seven.Vue3/src/views/system`）

## API

| 接口 | 说明 |
|------|------|
| POST /api/Builder/GetTableTree | 配置树 + 命名空间列表 |
| POST /api/Builder/LoadTableInfo | 新建/加载单表配置 |
| GET /api/Builder/loadTableInfo | 加载全部表配置 |
| POST /api/Builder/Save | 保存表与列配置 |
| POST /api/Builder/syncTable | 同步数据库表结构 |
| POST /api/Builder/CreateModel | 生成 Entity 文件 |
| POST /api/Builder/CreateServices | 生成 Service 接口/实现/Controller 骨架 |
| POST /api/Builder/CreateVuePage | 生成 Element Plus CRUD Vue 页 |
| POST /api/Builder/delTree | 删除空树节点 |
| POST /api/Sys_Dictionary/GetBuilderDictionary | 生成器 UI 字典 |

## 模板目录

`Seven.WebApi/Template/`：

- `VuePage.html` — Element Plus 列表 + 表单（多选、批量删除、导入导出、列设置、查询区、主子表、扩展按钮 / hooks）
- `VueExtension.ts.html` — 页面扩展文件空模板（自定义按钮，首次生成）
- `ServiceImpl.html` / `ServiceInterface.html` / `Controller.html` — 后端骨架（含 Excel 导入/导出）

生成 Vue 时会尝试创建 `Seven.Vue3/src/extension/{文件夹}/{表名}.ts`；**已存在则不覆盖**。自定义按钮见 [11-生成页自定义按钮](./11-生成页自定义按钮.md)；列设置、查询、hooks、主子表（含 `Sys_TableDetail`）见 [12-生成页配置](./12-生成页配置.md)。

`CrudHelper.PaginateAsync` 支持 `Wheres` JSON 过滤（生成 Service 自动具备）。生成业务类后需**重启 WebApi** 使路由与 DI 生效。已有表需重新「生成业务类」才会带上 import/export 接口。

## 注意事项

- 生成前备份已有代码，避免覆盖自定义逻辑
- `CreateServices` 输出为骨架代码，复杂业务请手动扩展
- 模板路径由 `Seven.Builder/ProjectPath.cs` 解析 Solution 根目录
