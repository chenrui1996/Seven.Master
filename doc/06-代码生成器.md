# 代码生成器

## 概述

Seven.Builder 模块从 Legrand.Builder 迁移，支持根据数据库表结构自动生成前后端 CRUD 代码。

## 核心表

- `Sys_TableInfo`：表信息（表名、中文名、命名空间等）
- `Sys_TableColumn`：列信息（字段名、类型、是否可编辑等）

## 使用流程

1. **同步表结构**：代码生成 → 选择数据库 → 同步表到 Sys_TableInfo
2. **配置生成选项**：编辑列属性（是否显示、是否可搜索、控件类型等）
3. **生成代码**：点击生成，输出 Entity、Service、Controller、Vue 页面

## API

| 接口 | 说明 |
|------|------|
| GET /api/Builder/loadTableInfo | 加载表列表 |
| POST /api/Builder/syncTable | 同步数据库表结构 |
| POST /api/Builder/createEntityModel | 生成实体 |
| POST /api/Builder/createServices | 生成 Service/Repository |
| POST /api/Builder/createVuePage | 生成 Vue 页面 |

## 生成规则

- 实体继承 `BaseEntity`，使用 CodeFirst Configuration
- Service 继承通用 CRUD 基类
- Controller 路由 `/api/{TableName}/`
- Vue 页面使用 Element Plus Table + Form

## 注意事项

- 生成前备份已有代码，避免覆盖自定义逻辑
- 复杂业务建议在生成后手动扩展 Partial Service
