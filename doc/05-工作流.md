# 工作流

> 需开启 `Features:WorkFlow=true`（见 [14-功能开关](./14-功能开关.md)），否则 API 返回 404，前端不显示流程菜单。

## 概述

Seven 迁移了 Legrand 的自定义审批工作流引擎，支持按角色/部门/用户多步审批（线性步骤；条件分支未产品化）。

## 核心表

| 表 | 说明 |
|----|------|
| Sys_WorkFlow | 流程定义 |
| Sys_WorkFlowStep | 流程步骤 |
| Sys_WorkFlowTable | 流程实例 |
| Sys_WorkFlowTableStep | 实例步骤状态 |
| Sys_WorkFlowTableAuditLog | 审批日志 |

## 业务表要求

需要走审批的业务表必须包含 `AuditStatus` 字段：

| 值 | 含义 |
|----|------|
| 0 | 待审核 |
| 1 | 审核通过 |
| 2 | 审核中 |
| 3 | 审核未通过 |
| 4 | 驳回 |

## API

| 接口 | 说明 |
|------|------|
| POST /api/Sys_WorkFlow/submit | 提交审批 |
| POST /api/Sys_WorkFlow/audit | 审批操作（通过/驳回） |
| GET /api/Sys_WorkFlowTable/getPageData | 我的待办/已办 |

## 配置流程

1. 工作流管理 → 新建流程，绑定业务表 TableName
2. 配置步骤：审批人类型（角色/用户/部门负责人）
3. 业务表单提交时调用 submit 接口

## 前端

- 流程定义：`Seven.Vue3/src/views/system/Sys_WorkFlow.vue`
- 我的审批：`Seven.Vue3/src/views/system/Sys_WorkFlowTable.vue`

## 生成页接入 submitAudit

在业务表的 `*.extension.ts` 中通过 `hooks.submitAudit` 提交审批（或由 CrudPanel 在配置了该钩子时自动显示「提交审批」行按钮）：

```ts
import type { PageExtension } from '@/extension/types'
import http from '@/api/http'
import { ElMessage } from 'element-plus'

const extension: PageExtension = {
  hooks: {
    submitAudit: async ({ row, tableName }) => {
      const tableKey = String(row.deviceId ?? row.id ?? '')
      if (!tableKey) {
        ElMessage.warning('无法识别业务主键')
        return
      }
      const res = await http.post('/api/Sys_WorkFlow/submit', { tableName, tableKey })
      if (res.status) ElMessage.success('已提交审批')
    },
  },
  rowButtons: [
    {
      key: 'submitAudit',
      label: '提交审批',
      type: 'success',
      visible: (row) => row.auditStatus === 0 || row.auditStatus == null,
      onClick: async (ctx) => {
        await extension.hooks!.submitAudit!({ row: ctx.row, tableName: 'Your_Table' })
        await ctx.reload()
      },
    },
  ],
}

export default extension
```

说明：`tableName` 须与流程定义中的 `WorkTable` 一致；`tableKey` 为业务主键值的字符串形式（非列名）。主键列名在流程定义的 `WorkTableKey` 中配置。

## 步骤审批人类型（StepType）

| 值 | 含义 |
|----|------|
| 1 | 角色（StepValue=角色Id，逗号分隔） |
| 2 | 用户（StepValue=用户Id） |
| 3 | 部门（StepValue=部门Id） |

## API（补充）

| 接口 | 说明 |
|------|------|
| POST /api/Sys_WorkFlow/listDefinitions | 流程列表 |
| POST /api/Sys_WorkFlow/saveDefinition | 保存流程+步骤 |
| POST /api/Sys_WorkFlow/getDefinition | 流程详情 |
| POST /api/Sys_WorkFlowTable/getPageData | 待办/已办（wheres scope=todo\|done） |
