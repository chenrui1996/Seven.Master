## C. 高频问答

### C1. 为什么 WMS 和 WCS 放一个进程？

**答**：共享库位与库存真相，减少分布式事务；用 **包边界 + 表前缀 + 总线 Leg** 隔离设备算法。若一上来拆微服务，库位一致性与联调成本更高。后续真要拆，总线已是自然边界。

### C2. Features 关了 WMS 菜单，接口还能调吗？

**答**：能。WMS/WCS **模块 UI 开关只藏菜单**，后端服务始终注册。基础设施开关（HotStore、MQ…）才会 Stub/404。这样避免「藏菜单卸调度」。

### C3. HotStore 和 Redis 缓存有什么区别？

**答**：缓存是加速只读、可穿透回源；HotStore 是调度 **运行时真相源**，预热后 miss 不回库，提供 Acquire/Release，脏数据异步批量落库。四向边占用走 `fw:`，不能拿延迟双删那套打节拍。

### C4. 库存如何保证不被 WCS 写乱？

**答**：可扣减只认 `Wms_Stock`。包内无第二套库存。分配用 `IsBooked`，到位用占用与容器字段。运输完成统一进 `WmsTransportCompletionHandler`。出库审核可先扣 AvailableQty 做预留。

### C5. 总线为什么「薄」？

**答**：总线只表达「容器 A→B + PackId」，不合并各包路网，不实现寻路。跨包靠交接位。厚逻辑留在 Pack，避免中央上帝服务。

### C6. 双深怎么防「孤二深」？

**答**：选位时深位仅当同组更浅已占用/预约；Booking 时同 BinGroup 相关空位一并预约。出库若深位被浅位挡，DepthGuard 抬升深位 Pri 并建 StackerTransfer 先移浅货。

### C7. 四向跨层为什么不拆多段 Bus？

**答**：对 WMS 仍是一次搬运。跨层联锁、同口排队、失败重试是提升机领域问题，收在 `FourWayHoistOrchestrator` 的 ToSrcAp → HoistLift → FromDesEp。总线契约稳定、更好测。

### C8. 停车位并发怎么防超卖？

**答**：`Fw_ParkingLedger` 三态 Free/Reserved/Occupied；预订用 `UPDATE … WHERE Status=Free` 条件更新。无空闲则 Suspended，周期唤醒。真正 Running 后再 Occupied。

### C9. 仿真怎么切真机？

**答**：业务依赖 `IEquipmentTriggerPort` 的申请/下发/反馈语义。现在 InMemory + 运维/测试 API；Phase H 换 S7/Modbus/Socket 实现，**业务不解析报文**。DeviceComm 提供协议与规则引擎，但不直接绑死在包状态机里。

### C10. 你们测试怎么做？

**答**：Seven.Tests 里按域名空间组织 E2E，例如 InboundToStacker、StackerDoubleDeep、FourWayHoist、Parking。用 `dotnet test --filter` 切片回归。关键路径覆盖「组盘→总线→包→段反馈→落账」。

### C11. 还有什么没做？

**答（诚实）**：Phase H 真机 Port 与多活写者；四向 F6 Promote/模拟器生产闭环；PDA 拣选发货离线；OAuth、多库租户、独立 Repository 等平台愿景项。当前优先保证单活联调与账本正确。

### C12. 同仓堆垛+四向如何共存？

**答**：`EnabledPackIds`；货位前缀 `Stk.`/`Fw.`；Zone/Aisle/Location 带 PackId；跨包走 HandoverLink + 多段 Leg。包禁止互改对方 HotStore / 合成统一路网。共享 TriggerPort 时用申请点归属做 NG 静默，防误 Reject。
