# 快速开始

## 环境要求

| 工具 | 版本 |
|------|------|
| .NET SDK | 8.0+ |
| Node.js | 18+ |
| MySQL / SQL Server / PostgreSQL | 任选（迁移以 MySQL 为基准） |
| Redis | 可选（`Cache:Provider=Redis`） |
| RabbitMQ | 可选（`Features.MessageQueue` + Provider=RabbitMQ） |
| MinIO | 可选（`Features.MinIO` + `MinIO:Enabled`） |

## 1. 目录

```
Seven.Master/
├── Seven.Net8/       # 后端
├── Seven.Vue3/       # 前端
├── deploy/           # Nginx / K8s
├── doc/              # 文档
└── docker-compose.yml
```

## 2. 后端配置

编辑 `Seven.Net8/Seven.WebApi/appsettings.json`：

```json
{
  "Database": {
    "Provider": "MySql",
    "ConnectionString": "Server=127.0.0.1;Database=seven;User=root;Password=root;",
    "MigrateOnStartup": false
  },
  "Cache": {
    "Provider": "Memory",
    "RedisConnectionString": "127.0.0.1:6379"
  },
  "Jwt": {
    "Secret": "YourSecretKeyAtLeast32CharactersLong!",
    "Issuer": "Seven",
    "Audience": "Seven",
    "AccessTokenMinutes": 15,
    "RefreshTokenDays": 7
  },
  "Features": {
    "WorkFlow": false,
    "Quartz": false,
    "SignalR": true,
    "Alarm": true,
    "MessageQueue": false,
    "Outbox": false,
    "Mail": false,
    "MinIO": false,
    "Tenant": false,
    "Captcha": false,
    "RateLimit": true,
    "Idempotency": true,
    "DataScope": true,
    "AuditInterceptor": true,
    "Builder": true,
    "HotStore": false
  }
}
```

`Database:Provider`：`MySql` / `SqlServer` / `PgSql`。

**简单项目**：保持 `Features` 默认即可（工作流/定时任务/MQ 等关闭）。需要时再打开，见 [14-功能开关](./14-功能开关.md)。路径/流量等高频读写见 [15-热数据HotStore](./15-热数据HotStore.md)。

开发环境可在 `appsettings.Development.json` 设 `Database:MigrateOnStartup: true`。

## 3. 数据库迁移

```bash
cd Seven.Master/Seven.Net8
dotnet tool restore
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

新增实体后：

```bash
dotnet ef migrations add <Name> --project Seven.Infrastructure --startup-project Seven.WebApi
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

## 4. 启动后端

```bash
cd Seven.Master/Seven.Net8
dotnet run --project Seven.WebApi
```

- API：http://localhost:5000  
- Swagger：http://localhost:5000/swagger  
- 功能开关：http://localhost:5000/api/config/features  
- 默认账号：`admin` / `123456`

## 5. 启动前端

```bash
cd Seven.Master/Seven.Vue3
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。前端启动会拉取 Features 并隐藏未启用模块的菜单。

## 6. 如何查看日志

| 类型 | 查看位置 | 说明 |
|------|----------|------|
| **系统操作/审计日志** | 前端：**系统管理 → 日志管理**（`/Sys_Log`） | 表 `Sys_Log`；登录、请求与字段审计（`Features.AuditInterceptor`）等 |
| **运行时文件日志** | `Seven.Net8/Seven.WebApi/logs/seven-YYYYMMDD.log` | Serilog 按天滚动；同时输出到启动 API 的控制台 |

权限：日志页需 `Sys_Log.Search`（种子菜单「日志管理」已含 Search；非 admin 需在角色中勾选）。  
细节见 [02-后端开发指南 § 日志](./02-后端开发指南.md#日志)。
