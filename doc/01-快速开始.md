# 快速开始



## 环境要求



| 工具 | 版本 |

|------|------|

| .NET SDK | 8.0+ |

| Node.js | 18+ |

| MySQL / SQL Server / PostgreSQL | 任选其一（**迁移文件以 MySQL 为基准**，与 Docker Compose 一致） |

| Redis | 可选（缓存 Provider=Redis 时需要） |

| RabbitMQ | 可选（MessageQueue Provider=RabbitMQ 时需要） |

| MinIO | 可选（文件上传时需要） |

## 2. 后端配置



编辑 `Seven.Master/Seven.Net8/Seven.WebApi/appsettings.json`：



```json

{

  "Database": {

    "Provider": "MySql",

    "ConnectionString": "Server=127.0.0.1;Database=seven;User=root;Password=root;"

  },

  "Cache": {

    "Provider": "Memory",

    "RedisConnectionString": "127.0.0.1:6379"

  },

  "Jwt": {

    "Secret": "YourSecretKeyAtLeast32CharactersLong!",

    "Issuer": "Seven",

    "Audience": "Seven",

    "AccessTokenMinutes": 15,

    "RefreshTokenDays": 7

  }

}

```



`Database:Provider` 支持：`MySql`、`SqlServer`、`PgSql`。



## 3. 数据库迁移（EF Core Migrations）



项目使用 **EF Core Migrations** 管理表结构（`Seven.Infrastructure/Migrations/`）。是否在启动时自动迁移由 `Database:MigrateOnStartup` 控制（开发环境默认 `true`，生产默认 `false`）。



### 首次 / 升级数据库



```bash

cd Seven.Master/Seven.Net8

dotnet tool restore

dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi

```



开发环境也可直接 `dotnet run`：`appsettings.Development.json` 中 `MigrateOnStartup=true` 时，`DbSeeder` 会自动迁移。



### 新增实体后



```bash

dotnet ef migrations add <MigrationName> --project Seven.Infrastructure --startup-project Seven.WebApi

dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi

```



### 从旧版 EnsureCreated 升级



若数据库由早期 `EnsureCreated` 创建（无 `__EFMigrationsHistory` 表），开发环境建议 **删库重建** 后执行 `database update`；生产环境需 DBA 评估后手动 baseline 或迁移数据。

## 7. 常见问题



**Q: 数据库连接失败？**  

检查 `Database:Provider` 与连接串是否匹配，确保数据库已创建。



**Q: dotnet ef 命令找不到？**  

在 `Seven.Net8` 目录执行 `dotnet tool restore`，或使用 `dotnet ef`（需全局安装 `dotnet-ef` 8.0.x）。



**Q: 如何切换 Redis 缓存？**  

设置 `Cache:Provider` 为 `Redis` 并配置 `RedisConnectionString`。



**Q: 如何启用消息队列？**  

默认 `MessageQueue:Provider` 为 `None`（无需 RabbitMQ）。生产或 Docker 环境设为 `RabbitMQ`，详见 [10-消息队列指南](./10-消息队列指南.md)。



**Q: 从 Legrand 迁移数据？**  

参见 [scripts/migrate-data.sql](../scripts/migrate-data.sql) 与 [07-部署指南](./07-部署指南.md)。
