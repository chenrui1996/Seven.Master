# 快速开始

## 环境要求

| 工具 | 版本 |
|------|------|
| .NET SDK | 8.0+ |
| Node.js | 18+ |
| MySQL / SQL Server / PostgreSQL | 任选其一 |
| Redis | 可选（缓存 Provider=Redis 时需要） |
| MinIO | 可选（文件上传时需要） |

## 1. 克隆与目录

```
Junheinrich.Master/
├── Seven.Master/
│   ├── Seven.Net8/      # 后端
│   └── Seven.Vue3/      # 前端
├── doc/                 # 文档
└── 系统迁移实现大纲.md
```

## 2. 后端配置

编辑 `Seven.Master/Seven.Net8/Seven.WebApi/appsettings.json`：

```json
{
  "Database": {
    "Provider": "MySql",
    "ConnectionString": "Server=127.0.0.1;Database=seven;User=root;Password=root;"
  },
  "Cache": {
    "Provider": "Memory",
    "RedisConnectionString": "127.0.0.1:6379"
  },
  "Jwt": {
    "Secret": "YourSecretKeyAtLeast32CharactersLong!",
    "Issuer": "Seven",
    "Audience": "Seven",
    "AccessTokenMinutes": 15,
    "RefreshTokenDays": 7
  }
}
```

`Database:Provider` 支持：`MySql`、`SqlServer`、`PgSql`。

## 3. 数据库迁移

```bash
cd Seven.Master/Seven.Net8
dotnet ef database update --project Seven.Infrastructure --startup-project Seven.WebApi
```

## 4. 启动后端

```bash
cd Seven.Master/Seven.Net8/Seven.WebApi
dotnet run
```

默认地址：`http://localhost:5000`，Swagger：`http://localhost:5000/swagger`

## 5. 启动前端

```bash
cd Seven.Master/Seven.Vue3
npm install
npm run dev
```

默认地址：`http://localhost:5173`

## 6. 默认账号

首次启动会自动 Seed 管理员：

- 用户名：`admin`
- 密码：`123456`

## 7. 常见问题

**Q: 数据库连接失败？**  
检查 `Database:Provider` 与连接串是否匹配，确保数据库已创建。

**Q: 如何切换 Redis 缓存？**  
设置 `Cache:Provider` 为 `Redis` 并配置 `RedisConnectionString`。

**Q: 从 Legrand 迁移数据？**  
参见 [scripts/migrate-data.sql](../Seven.Master/scripts/migrate-data.sql) 与 [07-部署指南](./07-部署指南.md)。

## 8. 运行测试

后端已包含 `Seven.Tests` xUnit 项目，覆盖单元测试与 API 集成测试。

```bash
cd Seven.Master/Seven.Net8
dotnet test
```

| 类别 | 文件 | 说明 |
|------|------|------|
| 单元测试 | `Unit/BcryptPasswordHasherTests.cs` | BCrypt 哈希与校验 |
| 单元测试 | `Unit/MemoryCacheServiceTests.cs` | 内存缓存与延迟双删 |
| 单元测试 | `Unit/AuthServiceTests.cs` | 登录、改密业务逻辑 |
| 集成测试 | `Integration/HealthApiTests.cs` | 健康检查接口 |
| 集成测试 | `Integration/AuthApiTests.cs` | 登录、Token 刷新、鉴权 |

集成测试使用 InMemory 数据库，环境变量 `Testing`，与生产数据库隔离。

前端构建验证：

```bash
cd Seven.Master/Seven.Vue3
npm run build
```
