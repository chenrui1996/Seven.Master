# 健康检查看板（HealthChecks.UI）

Seven API 使用 [AspNetCore.Diagnostics.HealthChecks](https://github.com/Xabaril/AspNetCore.Diagnostics.HealthChecks) 做依赖探测，并通过 **HealthChecks.UI** 提供可视化看板。

实现入口：`Seven.WebApi/HealthChecksExtensions.cs`（`AddSevenHealthChecks` / `MapSevenHealthChecks`）。

---

## 1. 怎么打开

1. 启动 API（见 [01-快速开始](./01-快速开始.md)），默认开发地址为 `http://localhost:5000`。
2. 浏览器打开：

| 地址 | 用途 |
|------|------|
| [http://localhost:5000/health-ui](http://localhost:5000/health-ui) | **看板**：各检查项状态、历史曲线 |
| [http://localhost:5000/health](http://localhost:5000/health) | **JSON 探针**：K8s / 脚本用；明细格式供 UI 消费 |
| [http://localhost:5000/api/Health](http://localhost:5000/api/Health) | 轻量存活接口（Controller），与看板无关 |

看板与 `/health` **匿名可访问**（与 K8s 探针一致）。生产若需鉴权，需自行加网关或中间件，当前未内置登录。

Docker Compose 部署时 API 端口仍为 `5000`，见 [07-部署指南](./07-部署指南.md)。

---

## 2. 看板上看什么

- 顶部列出已配置的监控端点（本项目为 **seven-api**，轮询本机 `/health`）。
- 默认约 **每 15 秒** 刷新一次。
- 各检查项颜色大致表示：
  - **绿色 Healthy**：正常
  - **黄色 Degraded**：可用但有降级（例如 MinIO 可达但桶不存在）
  - **红色 Unhealthy**：失败（连接不上等）
- 可点开单项查看最近探测历史（内存存储，**进程重启后清空**）。

若页面空白：先直接打开 `/health`，确认返回 JSON 且含各检查明细；再刷新 `/health-ui`。

---

## 3. 会出现哪些检查项

未启用的可选依赖 **不会注册**，看板里也就看不到该项。

| 名称 | 何时出现 | 探测内容 |
|------|----------|----------|
| `self` | 始终 | 进程存活 |
| `database` | 始终 | 按 `Database:Provider` 连库（MySql / SqlServer / PgSql） |
| `redis` | `Cache:Provider` = `Redis` 且连接串非空 | Redis Ping |
| `rabbitmq` | `MessageQueue:Provider` = `RabbitMQ` | AMQP 连接 |
| `minio` | `MinIO:Enabled` = `true` | 只读 `BucketExists`（**不建桶**） |

本地默认常为 Memory 缓存、MQ=`None`、MinIO 关闭时，看板里通常只有 **self + database**。要验证 Redis/MQ/MinIO，先在 `appsettings` 打开对应配置并确保服务可达。

---

## 4. 与 K8s / 运维的关系

- 探针请继续用 **`/health`**（见 `deploy/k8s/api-deployment.yaml`），不要用 `/health-ui`。
- 任一已注册检查变为 **Unhealthy** 时，`/health` 通常返回非 200，探针会判失败。
- **Degraded** 默认仍可能是 200（例如 MinIO 缺桶），看板会显示黄态，但不一定摘流。
- UI 历史存在进程内存中，多副本各自独立，不适合当作集中监控；资源与流量曲线见 [18-指标与监控](./18-指标与监控.md)。

---

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| 看板空白 / 一直 Loading | 确认 API 已启动；访问 `/health` 是否 200；浏览器控制台是否有跨域或 404 |
| 只有 self、database | 正常：可选依赖未启用则不注册 |
| Redis/MQ 红了但本地不想测 | 把 Provider 改回 Memory / None，重启后该项从看板消失 |
| 重启后历史没了 | 预期行为（InMemory）；当前未接业务库存储 |
| 生产暴露看板不放心 | 用反向代理限制 `/health-ui` 内网访问，或仅开放 `/health` |
